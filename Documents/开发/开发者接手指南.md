## 2. 开课冻结面（2026-09-27 已钉）

### 2.1 库版本

| 组件 | 版本 |
| ---- | ---- |
| CRT / libtoyos | **1.4.0** |
| libToyGfx | **1.3.0** |

| libFsUtil | **1.0.0** |
| SDK 包 `Tools/Sdk/VERSION` | **1.0.0-course**（与上表无关） |

核对：

```bash
rg -n 'VERSION_STRING' User/include/toyos/version.h User/include/ToyGfx.h \
  User/include/ToyUi.h User/include/ToyNet.h User/include/FsUtil.h
```

### 2.2 Syscall（易错）

- **权威号表**：`Include/Abi/SyscallABI.h`；用户侧 `User/include/toyos/syscall.h` **#include** 该头（不是另一套 0–29）。  
- **号段**：进程 0–99（实际常用 50+）、信号 100–199、内存 200–299、文件 300+、目录 500+、管道 600+、时间 700+、网络 800+、GUI **1000+** / 1100+。  
- **禁止**学生文档再写旧 GUI 号 18/19/20/21。  
- **未知号**：返回 **`-ENOSYS`（-38）**；串口 `syscall: unknown` **最多 8 次**后抑制。  
- **自动验**：`./build.sh` 后  
  `cd ../ToyImage/Scripts && ./test-enosys.sh` → `enosys: ok r=-38`。

### 2.3 `wait`（非 POSIX）

| | |
|--|--|
| 裸 syscall | `rax`=子 pid，`rdx`=退出码 0–255 |
| CRT `wait(&status)` | `*status = (exit & 0xff) << 8` |
| `WEXITSTATUS(s)` | `(s >> 8) & 0xff` |
| 无子 | `rax=-1`；`WNOHANG` 且子存活 → `0` |
| **没有** | `waitpid` / 按 pid 等待 |

### 2.4 文件红字

- `fopen("w")` **不截断** → 先 `remove(path)` 再 `fopen(path,"w")`。  
- `open` 的 flags 内核多半忽略。  
- **`write` 返回 0 视为错误**（与 read EOF=0 不同）。

### 2.5 GUI / HID

`ToyUiPoll`：`0` 无 / `1` 关 / `2` 空白点击 / `100+id` 按钮 / `200+` 复选 / `220+` 列表 / `240+` 输入焦点 / `300+hid` 键 / `-1` 错。

常用 HID：Enter `0x28`、Esc `0x29`、Backspace `0x2A`、空格 `0x2C`、方向 `0x4F`–`0x52`、字母 `0x04`–。  
`DamageRect` 单次 **≤64×64**。

### 2.6 网络

- 内核默认 `LWIP=1`；Guest 先 **`lwip on`**。  
- POSIX：`connect`/`bind` + `sockaddr` **网络序**（`<sys/socket.h>`）。  
- 便利：`ToyNetConnect(fd, ip, port)` **主机序**（`<ToyNet.h>`，ABI 2.x）。  
- Arm64/RiscV virt：**无 LwIP 端口**，编时 `LWIP=0`。

## 3. 仓库与日常命令

三仓同级：`ToyKernel` / `ToyBoot` / `ToyImage`。

```bash
# 编内核（x86；默认同步 RootFs/X64）
cd ToyKernel && ./build.sh

# 三架构（开课前已验过）
./build.sh && ./build.sh arm64 && ./build.sh riscv

# QEMU x86
cd ../ToyImage && ./Scripts/run-split.sh
./Scripts/smoke-boot.sh

# 统一验收（须 ToyImage 旁路；expect 脚本在 Scripts/ 下被调用）
cd ../ToyKernel && ./Tools/Scripts/test-all.sh
# → runtests×3 + smoke-boot + smoke-virt + test-shell/user/fs/enosys

# SDK（Build/ gitignore）
./Tools/build-sdk.sh    # Build/ToySDK.tar.gz ；VERSION=1.0.0-course
```

**U 盘真机**：暗号 **TBU** → `ToyImage/Scripts/sync-kernel-usb.sh`（**喊 TBU 或 JX 需手测时自动执行**；TOYOS 已挂载则刷，未挂载黄字提示）。Wi‑Fi 家用见 `FW/WIFI_H.CFG`→`WIFI.CFG`。

## 4. 写代码时的硬规则（摘要）

1. 新 `.c` **≤300 行**；将满先拆同名子目录。  
2. 新符号 PascalCase + 层前缀；勿 `fb_init` / 乱序。  
3. 改 `Common/` / `User/` / `Include/` 时兼顾 **x86 / arm64 / riscv**（至少抽验另两架构 `./build.sh`）。  
4. JX 收口写清要不要手测；能量化的用 `test-*.sh` / `test-all.sh`。  
5. **TG** = 只 commit；**TS** = push；**GD** = 只挪路线图归档、不 commit。

## 7. 建议自学顺序（改内核时）

1. `User/Pkg` 出 ELF → `exec`（巩固 syscall/CRT）。  
2. 读 `Include/Abi/SyscallABI.h` + `Core/Syscall/Syscall.c`（分发与 ENOSYS）。  
3. 改一刀用户库（`User/Library/ToyUi`）看 ABI MAJOR 纪律。  
4. 驱动：拷 `HAL/X64/Drivers/_template/`，对照驱动指南 5 步。  
5. 动调度/FS 前读 `已完/可替换模块化架构规划.md` + `如何写一个*.md`。
