# 布局文件格式

> 状态：规范。配套：应用开发指南 §5.5、[`多页面分发.md`](多页面分发.md)。  
> 目标：学生写 `.uitxt` → `uitxt2h` → `MyAppUi.h` → 编译进 ELF。运行时零解析。

---

## 1. 为什么用布局文件

- 布局与逻辑分离：改坐标/文案不必翻 `OnId*`  
- **编译期**生成控件表，Guest **零解析、零读盘**  
- 设计器可导出 `.uitxt`；学生只填 `UiActions.c` 的 `/* TODO */`

路径（树迁后）：源在 `CodeE-User/Pkg/UiText/`（文档仍常写 `User/Pkg/`）；工具 `Tools/UiLayout/uitxt2h.py`。

---

## 2. `.uitxt` 格式规范

### 2.1 语法

- `#` 开头为注释；空行忽略  
- **第一行有效内容**必须是 `window`  
- 每行一个控件：`类型 id=... x=... y=... w=... h=... text="..."`  
- `id`：小写英文开头，英文/数字，无空格  
- `text`：双引号；数值：十进制整数  
- 字段顺序任意  

`window` 行：

```text
window "标题" 宽 高
```

### 2.2 控件类型

| 类型 | 生成 Kind | 运行时大致映射（现有 ToyUi） |
| ---- | --------- | ----------------------------- |
| `label` | `TOY_UI_WIDGET_LABEL` | `ToyUiSetLabel`（多 label 时后者覆盖） |
| `button` | `TOY_UI_WIDGET_BUTTON` | `ToyUiAddButton`（物理 id **0..3**） |
| `checkbox` | `TOY_UI_WIDGET_CHECKBOX` | `ToyUiAddCheckBox`（id 上限见 `ToyUi.h`） |
| `textbox` | `TOY_UI_WIDGET_TEXTBOX` | `ToyUiAddTextField` |

### 2.3 示例

```text
# MyApp.uitxt
window "MyApp" 1280 720
label  id=hello   x=20  y=20  w=200 h=24 text="Hello"
button id=ok      x=20  y=60  w=80  h=28 text="OK"
button id=cancel  x=120 y=60  w=80  h=28 text="Cancel"
checkbox id=chk   x=20  y=100 w=100 h=24 text="Enable"
```

### 2.4 错误处理

`uitxt2h`：**缺文件 / 首行非 window / 未知类型 / id 重复 / 缺字段** → stderr 说明 + **exit 1**。

## 3. `uitxt2h` 用法

### 3.1 命令行

```text
python3 Tools/UiLayout/uitxt2h.py MyApp.uitxt > MyAppUi.h
```

### 3.2 输出格式

- 头保护宏（自文件名）  
- `MYAPP_WIN_W` / `WIN_H` / `WIN_TITLE`  
- `enum { ID_HELLO = 0, ... }`  
- `static const TOY_UI_WIDGET gMyAppWidgets[]`  
- `MYAPP_WIDGET_COUNT`  
- 类型：若尚无独立 `ToyUiLayout.h`，生成头**内联** `TOY_UI_WIDGET_*`（不改 `ToyUi.h` ABI）

### 3.3 ID 分配

- 按出现顺序从 **0** 递增  
- `id=ok` → `ID_OK`  
- 重复 id → 报错退出

## 4. 编译期生成 vs 运行时解析

| 维度 | 编译期生成 | 运行时解析 |
| ---- | ---------- | ---------- |
| 启动速度 | 零开销 | 读盘 + 解析 |
| 内存占用 | 只有控件数组 | 解析器 + 临时缓冲 |
| 错误发现 | 编译前 | 运行时 |
| 盘上文件 | 只有 ELF | ELF + `.uitxt` |
| 学生理解 | 布局变成代码 | 运行时解析文本 |

本刀只做**左列**。

---

## 5. 逻辑坐标与 scale

- 设计画布固定 **1280×720**（`.uitxt` 的 `window` 推荐此值）  
- 运行时 `scale = 实际客户区宽 / 1280`（后续刀；本模板先原样像素）  
- 控件坐标乘 `scale`；字体按 `scale` 选档

## 6. Makefile 接入

`CodeE-User/Pkg/ToyUser.mk`：若定义 `UITXT`，则

```text
MyApp.uitxt → MyAppUi.h（uitxt2h）→ 再编 .o / ELF
```

包内：`make -C CodeE-User/Pkg/UiText` → `build/MYAPP.ELF`。

---

## 7. 学生模板用法

1. 改 `MyApp.uitxt`  
2. `make`（生成头 + ELF）  
3. 在 `UiActions.c` 填 `OnId*`  
4. 拷到 `ToyImage/RootFs/X64/` 后 `exec MYAPP.ELF`  

`ToyUiLoadWindow` 为模板内薄封装（`CreateWindow` + 按表 `Add*`），**不**进 `ToyUi.h`。

---

## 8. 已知限制

- 不支持嵌套容器 / 布局引擎 / 样式表 / 运行时热改  
- 现有 ToyUi 底栏按钮无自由 x,y；checkbox/textbox id 有上限  
- 多 label 仅保留最后一次 `SetLabel`  
- 未实现真 scale（§5 为约定，留给后续刀）
