> **目的**：把冷启动链路钉死，标出慢点 / 软退点，供「更快 + 更稳」改造对照。

> **日期**：2026-09-27（对照当前树）。

## 0. 先答：后台只有一个 worker 吗？

**专用后台任务只有一个：`worker`（`WorkerTask`）**，钉在 **BSP CPU0**。

它按优先级泵三件事（忙则 `continue`，空则 `HalCpuHalt`）：

1. **`StoreJobStep`** — 商店装卸（窗/Shell 只 Enqueue）  
2. **`HalIwlBgPump`** — iwl Wi‑Fi 固件/后台关联切片  
3. **`LwIpDhcpStep`**（真机 NIC epoch 变化时先 `LwIpDhcpRestart`）

**不是**「全系统只有这一处在干活」。还有协作轮询（同进程多任务，不是第二套 Worker 线程池）：

| 角色 | 任务 | 泵什么 |
| ---- | ---- | ------ |
| shell | `ShellTask` | 键鼠 dequeue、Present、COM1、`LwIpService`/`HalNetPoll` |
| gui | `GuiTask` | `GuiPollMouse` / 桌面时钟 |
| input | `InputTask`（仅 **SMP≥3** → CPU2） | `HalInputPoll`（xHCI/PS2） |
| idle\* | 每核一个 | halt |
| ktdemo | `KernelTask` 演示槽 | 教学进度（非 Store） |

稳态 HID：SMP≥3 走 `InputTask`；否则 Gui/Shell 的 `YieldForPollInput`。  
USB MSC 热拔：`DesktopTickClock`（~2 Hz）→ `HalUsbMscHotPoll`。  
Store 写盘长 IO：`StoreIoBreath` → `SchedulerIoBreath`（在 worker 上下文里保鼠标）。

**产品化不做**：Store 线程池、多作业并行队列（见路线图 `PR-S-job` 非目标）。

**多 Shell / 异步命令（2026-09-27）**：每窗独立 scrollback（`RaiseWindow` 挪槽时 `ConsoleSbShiftRaise` 跟随）；`net dhcp` / Shell `store …` 先 `HoldPrompt`，完成后再 `toyos>`；其它 Shell 可照常输入。  
**开机日志**：`Scheduler: AP entered idle` 夹在 `iwl bg=*` 中间属正常——`SchedulerStart` 后 AP 与 Worker（iwl 后台）并行。

## 1. 冷启动总览（x86 课机 / QEMU split）

```
加电 → OVMF
  → ToyBoot (BOOTX64.EFI)
       串口 → GOP → 读 Kernel.elf → ExitBootServices → jmp KernelEntry
  → KernelEntry / Startup.c → BOOT_INFO → KernelMain
       → KernelModulesRun(gModulesFull | Virt*)
       → 创建 shell / gui / worker [/ input]
       → SchedulerStart
  → 串口 "ToyOS ready…"；桌面已画；Shell 窗按需打开
```

Arm64/RiscV virt：**无 OVMF**，`-kernel` 进各自 Startup → 同 `KernelMain`（模块表可能是 `gModulesVirtDesktop`）。

## 2. ToyBoot（固件侧）

| 步 | 符号 / 文件 | 做什么 |
| -- | ----------- | ------ |
| 1 | `UefiMain` · `ToyBoot/Boot.c` | 最早串口；横幅 |
| 2 | `GetAndSetVideo` · `BootVideo.c` | 选 GOP 模式；清屏（Kernel 不再清） |
| 3 | `ReadKernelFile` · `BootKernel.c` | 找含 `TOYOS.ID` 的卷；`\Kernel.elf` 等 |
| 4 | `CheckAndLoadKernel` · `BootKernelLoad.c` | PT_LOAD → ~1MB；取入口 |
| 5 | ACPI / xHCI hint | RSDP、可选 xHCI MMIO |
| 6 | `JumpToKernel` | ExitBootServices；`BOOT_CONFIG*` → `KernelEntry` |

**慢点候选**：大分辨率 GOP；从慢 U 盘读 `Kernel.elf`。

## 3. Kernel 早期

| 步 | 符号 | 做什么 |
| -- | ---- | ------ |
| 1 | `KernelEntry` · `HAL/X64/Startup.c` | 切早期栈 |
| 2 | `BootInfoFromUefi` | FB / 内存图 / GOP / xHCI / RSDP → `BOOT_INFO` |
| 3 | `KernelMain` · `Core/Kernel.c` | 串口、Video 指针、Font/Theme 骨架、BootLog |
| 4 | `KernelModulesRun` | 见下表；模块间可 `HalInputPoll`（防真机 event ring 溢） |
| 5 | 建任务 + `SchedulerStart` | 见 §0 |

串口 **`ToyOS ready`**：`InitializeConsole` → `ConsoleInitialize` → `MSG_CON_READY`（此时桌面通常已在 `Gui` 画完）。

## 4. 模块表（现行 · 以代码为准）

### 4.1 `gModulesFull`（真机 / QEMU OVMF 桌面）

`Core/KernelModules.c`（**Usb 在 FileSystem 之前** —— 旧技术手册表已过时）：

| # | 日志名 | Init | 职责 / 软退 |
| - | ------ | ---- | ----------- |
| 1 | Serial | `InitializeSerial` | COM1 |
| 2 | Memory | `InitializePhysicalMemory` | PMM |
| 3 | Driver | `InitializeDriver` | 枚举；**只 Probe BLOCK**（避 PS/2 挂死） |
| 4 | VirtualMemory | `InitializeVirtualMemory` | 页表、FB/MMIO、开分页 |
| 5 | Video | `InitializeVideo` | 背缓冲；**不再清屏**（接 Boot 黑底日志） |
| 6 | Cpu | `InitializeCpu` | GDT/IDT/LAPIC/syscall |
| 7 | SerialEarly | `InitializeSerialEarly` | COM1 再确认；**不**抢 USB-UART |
| 8 | Smp | `InitializeSmp` | 拉 AP |
| 9 | Usb | `InitializeUsb` | xHCI HID；无输入也 **Continue** |
| 10 | FileSystem | `InitializeFileSystem` | MSC/ATA… 挂卷；`TOYOS.ID`；可 `HalIwlClaim` / USB-UART |
| 11 | Network | `InitializeNetwork` | `NetInit`（失败不挡开机） |
| 12 | Gui | `InitializeGui` | `DbInit`→`ThemeLoad`→`GuiInit`/`DesktopInit`（墙纸/图标） |
| 13 | Scheduler | `InitializeScheduler` | 调度表 |
| 14 | Console | `InitializeConsole` | 内置命令 + ready 串口行 |

### 4.2 其它表

| 表 | 用途 | 相对 Full 的差异 |
| -- | ---- | ---------------- |
| `gModulesVirt` | 串口-only virt | 无 Video/Usb/Net/Gui |
| `gModulesVirtDesktop` | virt 桌面 | 无 Usb 行；输入多在 Cpu/virtio |

## 5. 调度起来之后

1. **idle** 每核；**worker→BSP**；**shell/gui→CPU1**（SMP>1）；**input→CPU2**（SMP≥3）。  
2. 桌面已就绪；任意键 / `shell` 开 Shell 窗。  
3. 真机插网后：worker 上 DHCP；iwl 长活在 `HalIwlBgPump`。

## 6. 已知慢点（优化候选）

按「体感影响 × 改动风险」大致排序：

| 优先级 | 位置 | 现象 | 稳妥方向（未开工） |
| ------ | ---- | ---- | ------------------ |
| P0 | `DesktopInit` 墙纸/图标 | U 盘上数秒级 | 延后加载 / 降分辨率 BMP / 缓存尺寸 |
| P0 | `FileSystem` MSC 认盘重试 | Live USB 慢 | 缩短空转；超时软退已有，可收紧 |
| P1 | `HalIwlClaim` + fw 读盘 | FS 阶段拉长 | **更晚 Claim** 或全丢 worker（开机先有线） |
| P1 | GOP 模式 / 4K | Boot+Video | 课机钉 1080p；避免无谓 SetMode |
| P2 | `DbInit`/`ThemeLoad` | Gui 前同步读 | 默认主题内存底稿，CFG 异步 |
| P2 | 模块间 `HalInputPoll` | 真机必要、QEMU 可减 | 按 `HalCpuIsHypervisor` 分支 |
| P3 | Store 整段写盘 | 装卸顿（非冷启动） | 已有 breath；写分块另刀 |

**稳优先于快的红线**（勿为加速拆掉）：

- Usb **先于** FS（MSC auto / NUC 键鼠）  
- 无 HID / 无 NIC / 无 WIFI.CFG → **软退 Continuable**，不挡桌面  
- Worker **不**在 Gui 里 Step（装卸卡鼠标已修）  
- 无线 **永不串口打 PSK**

## 7. 建议测量法（改之前先定量）

串口已有 `[Mod] <Name>`（BootLog Title Case）。建议：

```text
# 宿主机记时间戳（示例）
./Scripts/run-split.sh 2>&1 | ts '%H:%M:%.S' | tee boot.log
# 或手工对：
#   ToyBoot / COM1
#   [Mod] Serial … [Mod] Console
#   ToyOS ready
```

真机：同一 U 盘连跑 3 次，记 **ready 墙钟** 与 **桌面可点**（墙纸出齐）两档。

优化验收：**ready 不回退**；`smoke-boot.sh` / `test-all` 仍绿；NUC 无键鼠仍进桌面。
