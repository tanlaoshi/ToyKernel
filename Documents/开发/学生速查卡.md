# ToyOS 学生速查卡（A4 · 课程承诺面）

> 与 [`待做/开课前接口冻结与教学准备.md`](../待做/开课前接口冻结与教学准备.md) §一 冻结清单对齐。  
> 完整对照见 [`API速查.md`](API速查.md)。**不承诺**完整 POSIX / 线程 / TLS / 动态链接 / TTF。

---

## 进程

| 签名 | 成功 | 失败 / 注意 |
| ---- | ---- | ----------- |
| `pid_t fork(void)` | 子 `0`；父=子 Id | `-1` |
| `pid_t wait(int *status)` | 子 Id；`*status=(exit&0xff)<<8` | `-1` 无子；**无 pid 参**；`WEXITSTATUS(s)=(s>>8)&0xff` |
| `int execve(path, argv, envp)` | 不返回 | `-1` |
| `void exit(int status)` | — | 退出码 0–255 |
| `pid_t getpid(void)` / `getppid` | Id | 无父时 ppid=`0` |
| `int sched_yield(void)` | `0` | |
| `unsigned sleep(sec)` / `msleep(ms)` | 0 | 按调度节拍，**非墙钟** |

```c
pid_t p = fork();
if (p == 0) { exit(7); }
int st; wait(&st); /* WEXITSTATUS(st)==7 */
```

## 文件

| 签名 | 成功 | 失败 / 注意 |
| ---- | ---- | ----------- |
| `int open(path, flags)` | `fd≥0` | `-1`；内核**忽略** flags |
| `ssize_t read(fd,buf,n)` | 字节数；EOF=`0` | `-1` |
| `ssize_t write(fd,buf,n)` | 字节数 | `-1`；**`write=0` 视为错误** |
| `int close(fd)` / `lseek(...)` | `0` / 新偏 | `-1` |
| `FILE *fopen(path,mode)` | 非 NULL | NULL；**`"w"` 不截断**→先 `remove` 再 `fopen` |
| `printf` / `snprintf` | 字符数 | |

```c
remove("A.TXT");
FILE *f = fopen("A.TXT", "w");
fwrite("hi", 1, 2, f); fclose(f);
```

## GUI（libToyUi **1.2.0** / libToyGfx **1.3.0**）

| 签名 | 注意 |
| ---- | ---- |
| `ToyUiCreateWindow(title,w,h)` | 成功 `wid≥0` |
| `ToyUiSetLabel` / `AddButton(wid,id,label)` | `id` ∈ **0..3** |
| `ToyUiPoll(wid)` | 见下表；非阻塞 |
| `ToyGfxDamageText` / `DamageRect` | 单次 Rect **≤64×64**；大 `FillRect` 自动分块 |

| `ToyUiPoll` | 含义 |
| ----------- | ---- |
| `0` | 无事件 |
| `1` | 关窗 |
| `2` | 客户区点击未命中控件 |
| `100+id` | 按钮 |
| `200+id` / `220+id` / `240+id` | 复选 / 列表 / 输入焦点 |
| `300+hid` | 按键（方向 `0x4F`–`0x52`；Enter `0x28`；Esc `0x29`；Backspace `0x2A`；空格 `0x2C`；字母 `0x04`–） |
| `-1` | 无效 wid |

```c
int w = ToyUiCreateWindow("Hi", 320, 200);
ToyUiAddButton(w, 0, "OK");
for (;;) {
    int ev = ToyUiPoll(w);
    if (ev == 1) break;
    if (ev == TOY_UI_BUTTON_EVENT(0)) { /* … */ }
}
```

## 网络（libToyNet **2.0.1**；Guest 先 `lwip on`）

| 签名 | 注意 |
| ---- | ---- |
| `socket` / `connect` / `bind` / `listen` / `accept` | `<sys/socket.h>`；`sockaddr` **网络序** |
| `ToyNetConnect(fd, ip, port)` | **主机序**；课上便利 API |
| `ToyNetResolve(name, &ip)` | 点分 / `localhost` / 域名 |
| `send` / `recv` | 字节数；失败负 / `-1` |

```c
int fd = socket(AF_INET, SOCK_STREAM, 0);
ToyNetConnect(fd, ToyNetIpv4(10,0,2,2), 7);
```

## 红字（必背）

1. **`fopen("w")` 不截断** → `remove` 再 `fopen`。  
2. **`wait` ≠ POSIX `waitpid`**（无 pid；退出码在 CRT 里 `<<8`）。  
3. **旧 GUI syscall 18/19/20/21 禁用**；只用 1000+ / `ToyUi*`。  
4. 未知 syscall 返回 **`-ENOSYS`（-38）**，不崩。  
5. 编译：**禁止** `-pie` / 宿主 libc；用 `User/Pkg` 或 `Tools/Sdk`。  
6. ELF 盘名：**8.3 大写**（`MYAPP.ELF`）。
