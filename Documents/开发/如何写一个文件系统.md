# 如何写一个文件系统

默认内核用 `FS=fat`，源在 `Common/Modules/FileSystemFat/`。学生模板在 `Student/FileSystemRam/FileSystemRam.c`，默认不链进内核。

## 你要改的函数

`FS_OPS`（`Include/Vfs.h`）里属于后端政策的是：

| 函数 | 做什么 |
| ---- | ------ |
| `Mount` | 准备卷；合成盘可忽略 `StartLba`。 |
| `ReadFile` / `WriteFile` | 按路径读写整文件。 |
| `DeleteFile` / `Mkdir` / `Rmdir` / `Rename` | 可选；不支持可返回 `FAT_ERR_ROFS` / `FAT_ERR_INVAL`。 |
| `ListDir` / `ListEntries` | 列目录；`ListEntries` 填 `FAT_DIRECTORY_ENTRY`。 |
| `FileStat` / `FileSync` | 可选；空指针时 Vfs 层会返回 IO/错误。 |
| `ReadFileAt` / `WriteFileAt` | 可选；空 → `FAT_ERR_INVAL`。 |
| `Synthetic` | 1 = 无 Block（内存盘）；0 = 需要块设备。 |

卷前缀、`FileSystemResolve` / Activate、Block 挂载留在框架。业务走 `FileSystem*` / `Vfs*`，不要直接调 Fat 内部。

本模板是 **Synthetic 内存盘**：最多 8 个文件、每文件 256 字节；写不存在的路径会创建。`FS=ram` 时用同文件里的 `FatFsOps()` 别名顶替 FAT，这样 `FileSystemInitialize` 不用改。

## 怎么编译和测试

在 `ToyKernel` 目录：

```bash
./Scripts/runtests.sh fs
make FS=ram
```

第一条先后断言契约 stub 与 ram 模板。第二条把模板链进内核。默认的 `./build.sh` 仍然只链 fat。

`make FS=nosuch` 会报错，这是为了避免把未知目录扫进内核。

> `FS=ram` 的内核能编过，但不适合当日常启动根文件系统（没有真实磁盘 FAT）。课堂请用 Host `runtests` 评模板。
