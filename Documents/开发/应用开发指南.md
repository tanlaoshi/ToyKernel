## 一、5 分钟跑通 Hello World

### 1.1 前置条件

- Linux 或 WSL2
- gcc / ld / make
- QEMU（`qemu-system-x86_64`）
- 本仓库 **ToyKernel** 与兄弟仓 **ToyImage** 放在同一父目录下（见仓库根 [`README.md`](../../README.md)）

检查：

```bash
gcc --version
make --version
qemu-system-x86_64 --version
```

### 1.2 编译第一个应用

首次请先编内核（生成 CRT / `libtoyos.a`；`User/Pkg` 的 `make` 也会代调，但没有 Kernel 就无法进 QEMU）：

```bash
# 0. 编内核（默认 LWIP=1）
cd ToyKernel && ./build.sh

# 1. 进入应用模板目录
cd User/Pkg

# 2. 编译（生成 build/MYAPP.ELF）
make

# 3. 复制到 ToyImage 的 rootfs（FAT 8.3，文件名大写）
cp build/MYAPP.ELF ../../../ToyImage/RootFs/X64/MYAPP.ELF

# 4. 启动 ToyOS（盘 0 = ESP，盘 1 = rootfs）
cd ../../../ToyImage
./Scripts/run-split.sh
```

换名：`make PROG=HELLO2 SRCS=main.c`。课外独立目录：复制 `User/Pkg/`，构建时加 `TOYKERNEL=/path/to/ToyKernel`。

也可打独立 SDK（不把整个内核树当 include 路径）。**开课包号 `1.0.0-course`**。解压到任意目录即可 `make`：

```bash
# 仓库内生成（维护者；Dist/ 不入库）
cd ToyKernel && ./Tools/build-sdk.sh    # → Dist/ToySdk/ + Dist/ToySdk.tar.gz

# 只拿到 tar 时（任意目录，不必在 ToyKernel 里）
tar xzf ToySdk.tar.gz
make -C ToySdk/Examples/Hello           # → Examples/Hello/Build/MYAPP.ELF
# make -C ToySdk/Examples/Hello deploy TOYIMAGE=/path/to/ToyImage
# 其余：File Dir Pipe Fork Gui Blit Net Fs，见 SDK 内 Examples/README.md
# 自己的应用：cp ToySdk/Makefile.template myapp/Makefile ，设 TOYSDK=
```

详见 SDK 根 [`README.md`](../../Tools/Sdk/README.md)（打包后在 `ToySdk/README.md`）。

### 1.3 在 ToyOS 中运行

在 ToyOS 的 Shell 中输入：

```
toyos> exec MYAPP.ELF
```

看到 `ToyOS pkg template (CRT 1.4.0)` → 成功！（`printf` 可能只出现在 **QEMU 串口**，见第十二章。）

## 二、应用是什么

一个 ToyOS 应用，本质上是：

1. **一个静态链接的 ELF 文件**（x86-64，入口约 `0x40000000`，见 `User/user.ld`）
2. **运行在 Ring 3（用户态）**
3. **通过 syscall 与内核交互**
4. **可以使用 CRT + libc 子集 + libToyXxx**

不需要链接内核代码，不需要编译进内核。不要 `#include` `Include/` 或调用 `Hal*`。

---

## 三、你能用的头文件

头文件在 `User/include/`（`ToyUser.mk` 会自动加 `-I`）。

### 3.1 标准 C 头（libc 子集）

| 头文件 | 提供什么 | 缺口 |
|--------|----------|------|
| `<stdio.h>` | printf / sprintf / snprintf / puts / perror；**fopen / fread / fwrite / fseek** | 无 stdin FILE*；`fopen("w")` **不截断** |
| `<stdlib.h>` | malloc / free / **realloc / calloc** / exit / atoi / atol / abs / qsort | 无 strtol / getenv |
| `<string.h>` | strlen / strcmp / strncmp / strcpy / strncpy / **strstr / strchr / strcat / strdup** / mem* | — |
| `<unistd.h>` | read / write / close / **lseek** / fork / wait / pipe / dup / execve / brk / kill / mmap；**getpid / getppid**；**getcwd / chdir**；**sleep / usleep / msleep / clock_ms** | 无 `dup2`；无 libc 裸 `yield()`（用 `sched_yield`）；sleep≈调度节拍 |
| `<sched.h>` | `sched_yield()` | `toy_yield()` 为其宏别名 |
| `<fcntl.h>` | open + 标志宏（**内核忽略 flags**） | — |
| `<signal.h>` | signal / kill；SIGINT / SIGKILL / SIGTERM | 无 sigaction；教学级 handler |
| `<ctype.h>` | isdigit / isspace / isalpha | 极小集 |
| `<errno.h>` | errno；**含 `ENOSYS=38`** | — |
| `<dirent.h>` | OpenDirectory…；**`opendir`/`readdir`/`closedir` 宏/CRT** | 第 2 轨名仍可用；`TOY_DIR *` |
| `<sys/stat.h>` | `stat` / `fstat` | `st_mode` 仅 `S_IFDIR`/`S_IFREG` |
| `<sys/socket.h>` | POSIX 形 `socket`/`connect`/`bind`… + `htons` 等 | **网络序** sockaddr；实现链 `libToyNet` |
| `<sys/mman.h>` | mmap / munmap | 教学子集，见头文件注释 |
| `<sys/types.h>` | ssize_t / pid_t / off_t | — |

没有 `<sys/wait.h>`：`wait` / `WEXITSTATUS` 在 `<unistd.h>`。

### 3.2 ToyOS 专用头

| 头文件 | 提供什么 |
|--------|----------|
| `<toyos/syscall.h>` | syscall 号 + `toy_*` 包装（含 `toy_yield()`） |
| `<toyos/version.h>` | `TOYOS_CRT_VERSION_*` |
| `<toyos.h>` | 伞头（demo 用；正式程序建议按需 include） |
| `<ToySyscall.h>` | 兼容转发 → `toyos/syscall.h` |
| `<ToyUi.h>` | 窗口 / 标签 / 按钮 / 复选框 / 列表 / 输入框 |
| `<ToyGfx.h>` | 系统字约定 + 文字 damage + blit + 点/线/矩形 |
| `<ToyNet.h>` | socket + sockaddr 封装 + DNS（内核默认 `LWIP=1`；Guest 需 `lwip on`） |
| `<FsUtil.h>` | 路径拼接 / 列目录 / `TOYOS:` 前缀 |

### 3.3 不能用的头

- ❌ `Include/Hal.h`（内核 HAL）
- ❌ `Include/Driver.h`（驱动框架）
- ❌ `Include/Fat.h`（目录属性用 `<dirent.h>` 的 `TOY_ATTR_DIR`）
- ❌ 任何 `Common/` 下的内核头文件

**应用只能通过 syscall 与内核交互。**

## 五、系统调用与 CRT 速查

ToyOS **不是** Linux 式连续 0–29 号表。权威定义在 [`Include/SyscallABI.h`](../../Include/SyscallABI.h)（段内编号）；用户头 `toyos/syscall.h` 直接 `#include` 它。应用一般走 CRT / libToy*，不必手写 `toy_syscall`。

**号段（记忆用）**：进程 ~50+ · 信号/调度 150+ · 内存 250+ · 文件 350+ · 目录 500+ · 管道 650+ · 时间 700+ · 网络 850+ · GUI **1000+** / `DAMAGE_RECT` 1100。  
**未知号** → `-ENOSYS`（**-38**）；见 [`User/Apps/EnosysDemo.c`](../../User/Apps/EnosysDemo.c)。

### 5.1 进程

| 功能 | 函数 | 头文件 |
|------|------|--------|
| 退出 | `exit(int status)` | `<stdlib.h>` |
| 创建子进程 | `fork()` | `<unistd.h>` |
| 等待子进程 | `wait(int *status)` | `<unistd.h>`（**无 pid**；见下） |
| 执行程序 | `execve(path, argv, envp)` | `<unistd.h>` |
| 本进程 / 父 | `getpid` / `getppid` | `<unistd.h>` |
| 发信号 | `kill(pid, sig)` | `<signal.h>` |
| 注册 handler | `signal(sig, handler)` | `<signal.h>` |
| 让出 CPU | `sched_yield()`（`toy_yield` 宏别名） | `<sched.h>` / `<toyos/syscall.h>` |
| 延时 / 稳节拍 | `msleep` / `sleep` / `clock_ms` | `<unistd.h>`（课堂 tick≈ms；**非墙钟**） |

**`wait` 钉死（非 POSIX `waitpid`）**：

- 裸 syscall：子 pid → `rax`，退出码（0–255）→ `rdx`。  
- CRT：`*status = (exit & 0xff) << 8`；`WEXITSTATUS(s) = (s >> 8) & 0xff`。  
- 无子：`wait` 返回 `-1`；`WNOHANG` 且子仍存活 → `0`。

### 5.2 文件

| 功能 | 函数 | 头文件 |
|------|------|--------|
| 打开 | `open(path, flags)` | `<fcntl.h>` |
| 读 / 写 / 关 | `read` / `write` / `close` | `<unistd.h>` |
| 定位 | `lseek(fd, off, SEEK_SET/CUR/END)` | `<unistd.h>` |
| `FILE*` | `fopen` / `fread` / `fwrite` / `fseek` / `ftell` / `fclose`（无缓冲） | `<stdio.h>` |
| 文件状态 | `FileStat(path, stat)` | `<dirent.h>` |
| 打开目录 | `OpenDirectory(path)` → `TOY_DIR *` | `<dirent.h>` |
| 读目录 | `ReadDirectory(dir, ent)` | `<dirent.h>` |
| 关目录 | `CloseDirectory(dir)` | `<dirent.h>` |
| 路径拼接 / 多卷 | `FsUtilJoin` / `FsUtilToyosPath` / `FsUtilListDir` | `<FsUtil.h>` |

路径可带卷前缀：`TOYOS:HELLO.ELF`、`RES:`；空路径 `""` = 默认卷根。FAT **大小写不敏感文件名习惯按 8.3 大写**。  
`fopen("w")` **不会截断**（内核忽略 `O_TRUNC`）→ 清空请先 `remove(path)` 再 `fopen`；`"a"` 会 `lseek` 到文件末尾。  
`write` 返回 **0 视为错误**（`read` 的 EOF=`0` 仍正常）。管道 / 套接字上 `lseek` 失败，`errno=ESPIPE`。

### 5.3 进程间通信

| 功能 | 函数 | 头文件 |
|------|------|--------|
| 管道 | `pipe(fds)` | `<unistd.h>` |
| 复制 fd | `dup(fd)` | `<unistd.h>` |

### 5.4 内存

| 功能 | 函数 | 头文件 |
|------|------|--------|
| 调整堆 | `brk(addr)` | `<unistd.h>` |
| 映射 | `mmap` / `munmap` | `<sys/mman.h>` |

### 5.5 GUI

| 功能 | 函数 | 头文件 |
|------|------|--------|
| 创建窗口 | `ToyUiCreateWindow(title, w, h)` | `<ToyUi.h>` |
| 设置标签 | `ToyUiSetLabel(wid, text)` | `<ToyUi.h>` |
| 添加按钮 | `ToyUiAddButton(wid, id, label)`（id 0..3） | `<ToyUi.h>` |
| 轮询事件 | `ToyUiPoll(wid)` | `<ToyUi.h>`；返回值见下 |

**`ToyUiPoll` 返回值（与技术手册一致）**：`0` 无事件 · `1` 关窗 · `2` 客户区空白点击 · `100+id` 按钮 · `200+id` 复选 · `220+id` 列表 · `240+id` 输入焦点 · `300+hid` 按键 · `-1` 错误。  
HID 最小集：Enter `0x28` / Esc `0x29` / Backspace `0x2A` / 空格 `0x2C` / 方向 `0x4F`–`0x52`。
| 复选框 / 列表 / 输入框 | `ToyUiAddCheckBox` / `AddList` / `AddTextField` | `<ToyUi.h>` |
| 初始化（系统字） | `ToyGfxInitialize()`（恒 0；首绘前调用） | `<ToyGfx.h>` |
| 系统字根 | `ToyGfxSystemFontRoot()` → `"Assets/Fonts"` | `<ToyGfx.h>` |
| 文字 damage | `ToyGfxDamageText(wid, text)`（**不**传字体路径） | `<ToyGfx.h>` |
| 像素矩形 blit | `ToyGfxDamageRect(wid, desc)`（单次 ≤64×64） | `<ToyGfx.h>` |
| 点 / 线 | `ToyGfxDrawPixel` / `ToyGfxDrawLine` | `<ToyGfx.h>` |
| 填充 / 框 | `ToyGfxFillRect` / `ToyGfxDrawRect` | `<ToyGfx.h>` |

#### 系统字体（方案 C · `PR-S-bundle-font`）+ 私有字（`PR-S-app-font`）

- 内核启动扫 **`Assets/Fonts/*.FNT`**（宏 `TOY_GFX_SYSTEM_FONT_ROOT`）。应用**不要**自己拼系统字路径。
- 课写 GUI：`ToyUi*` / `ToyGfxDamageText` 前先 `ToyGfxInitialize()`；文字走内核**当前**字体。
- **可选私有字**：`Apps/<id>/PKG.TXT` 写 `font=Assets/xxx.FNT`（相对应用目录）。`ProcessExec` 装 ELF 时内核 `FontLoadPath` 并切当前字；进程退出 / 换应用后恢复。无 `font=` = 系统字。
- 用户态仍经 `ToyGfxDamageText`；**勿**在 Guest 里自行 `FontLoad`。

内核窗口槽最多 **6** 个（含桌面应用窗）。

### 5.6 网络（内核 `LWIP=1`；Guest 先 `lwip on`）

## 六、Hello World 完整代码

`User/Pkg/main.c`（`make` → `build/MYAPP.ELF`）：

```c
#include <stdio.h>
#include <toyos/version.h>

int main(void) {

```

CRT 支持 `main(argc, argv)`。若要打印参数，可改成：

```c
#include <stdio.h>

int main(int argc, char **argv) {
    int i;

    printf("Hello from ToyOS!\n");
    printf("argc = %d\n", argc);
    for (i = 0; i < argc; i++) {
        printf("argv[%d] = %s\n", i, argv[i]);
    }
    return 0;
}
```

## 七、文件操作示例

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    FILE *fp;
    const char *msg = "Hello from app!\n";
    char buf[128];
    size_t n;

    fp = fopen("TOYOS:NOTE.TXT", "w");
    if (!fp) {
        printf("fopen write failed\n");
        return 1;
    }
    fwrite(msg, 1, strlen(msg), fp);
    fclose(fp);

    fp = fopen("TOYOS:NOTE.TXT", "r");
    if (!fp) {
        printf("fopen read failed\n");
        return 1;
    }
    fseek(fp, 6, SEEK_SET);
    n = fread(buf, 1, sizeof(buf) - 1, fp);
    if (n > 0) {
        buf[n] = 0;
        printf("read: %s", buf);
    }
    fclose(fp);
    return 0;
}
```

仍可用 `open`/`read`/`write`/`lseek`。对照：仓库 `User/Apps/WriteFile.c` 用无前缀名 `USERNOTE.TXT`（走默认卷）。flags 宏可写，内核目前忽略；**`fopen("w")` 同样不截断**。

## 八、目录操作示例

`OpenDirectory` 返回 **`TOY_DIR *`**（失败 `NULL`），不是 int fd。属性宏是 **`TOY_ATTR_DIR`**。

```c
#include <stdio.h>
#include <dirent.h>

int main(void) {
    TOY_DIR *dir;
    TOY_DIR_ENT ent;
    int rc;

    dir = OpenDirectory("");
    if (!dir) {
        printf("OpenDirectory failed\n");
        return 1;
    }
    while ((rc = ReadDirectory(dir, &ent)) > 0) {
        printf("  %s%s\n", ent.Name, (ent.Attr & TOY_ATTR_DIR) ? "/" : "");
    }
    CloseDirectory(dir);
    return 0;
}
```

完整冒烟见 `User/Apps/DirDemo.c`（可列 `RES:`，并用 `FileStat`）。

## 九、进程操作示例

`wait` 是 `wait(int *status)`，**不能**写成 `wait(pid, &status)`（无 `waitpid`）。子进程 `return 42` 时，CRT 把退出码放进 `*status` 的高 8 位：用 `WEXITSTATUS(st)` 取回。

```c
#include <stdio.h>
#include <unistd.h>

int main(void) {
    pid_t pid = fork();
    int st;

    if (pid == 0) {
        printf("child pid=%d\n", (int)getpid());
        return 42;
    }
    if (pid > 0) {
        printf("parent=%d child=%d\n", (int)getpid(), (int)pid);
        if (wait(&st) < 0) {
            printf("wait failed\n");
            return 1;
        }
        printf("exit=%d\n", WEXITSTATUS(st)); /* 期望 42 */
    } else {
        printf("fork failed\n");
        return 1;
    }
    return 0;
}
```

管道见 `User/Apps/PipeDemo.c`：子写父读，父进程 `wait(0)`。

## 十、GUI 示例

最小 GUI（与 `User/Pkg/Gui/main.c` / `User/Apps/GuiDemo.c` 相同协议）。无事件时调用 **`toy_yield()`**。

```c
#include <stdio.h>
#include <unistd.h>
#include <ToyUi.h>
#include <toyos/syscall.h>

int main(void) {
    int wid;
    int ev;

    wid = ToyUiCreateWindow("MyApp", 400, 240);
    if (wid < 0) {
        printf("create window failed\n");
        return 1;
    }
    ToyUiSetLabel(wid, "Hello GUI");
    ToyUiAddButton(wid, 0, "OK");

    for (;;) {
        ev = ToyUiPoll(wid);
        if (ev == TOY_UI_EVENT_CLOSE) {
            break;
        }
        if (ev == TOY_UI_BUTTON_EVENT(0)) {
            ToyUiSetLabel(wid, "OK clicked!");
        } else if (ev == TOY_UI_EVENT_NONE) {
            toy_yield();
        }
    }
    return 0;
}
```

构建：`cd User/Pkg/Gui && make` → `build/MYGUI.ELF`。更完整的按钮见 `User/Apps/GuiDemo.c`。底层 `create_window` / `damage` / `poll_input` 见 `User/Apps/WinDemo.c`。

## 十一、网络示例（需 lwIP）

内核默认 `LWIP=1`。Guest 里先 **`lwip on`**，宿主机可 `nc -l -p 8888`。

**双轨（Net ABI 2.0.1）**：

| 轨 | API | 字节序 |
| -- | --- | ------ |
| 第 1 轨 | `<sys/socket.h>` 的 `connect`/`bind` + `sockaddr_in` | **网络序**（`htons`/`htonl`） |
| 第 2 轨 | `ToyNetConnect(fd, ip, port)` / `ToyNetBind` | **主机序**；`ToyNetIpv4(a,b,c,d)` |

旧课笔记里的 `connect(fd, ToyNetIpv4(...), port)` **应编不过**——请改成 `ToyNetConnect` 或 POSIX `connect`。

```c
#include <stdio.h>
#include <unistd.h>
#include <ToyNet.h>

int main(void) {
    int fd = socket(AF_INET, SOCK_STREAM, 0);

    if (fd < 0) {
        printf("socket failed\n");
        return 1;
    }
    /* 主机序便利 API（与 User/Pkg/Net/main.c 一致） */
    if (ToyNetConnect(fd, ToyNetIpv4(10, 0, 2, 2), 8888) != 0) {
        printf("connect failed\n");
        close(fd);
        return 1;
    }
    send(fd, "hello", 5, 0);
    close(fd);
    printf("ok\n");
    return 0;
}
```

模板：`User/Pkg/Net/main.c`。域名：`ToyNetResolve` 或 Shell `dns`。Arm64/RiscV virt 编时通常 `LWIP=0`，无网络端口。

## 十二、调试技巧

### 12.1 printf 走串口

焦点在用户窗时，`printf` **只走串口**，不画进窗口客户区（见技术手册 GUI 入门）。命令行 `exec` 的输出也请以串口为准。

```bash
cd ../ToyImage
./Scripts/run-split.sh 2>&1 | tee serial.log
```

### 12.2 在 ToyOS 中运行

```
toyos> exec MYAPP.ELF
toyos> exec MYGUI.ELF
toyos> exec MYNET.ELF
```

### 12.3 检查 ELF 格式

```bash
file build/MYAPP.ELF
# 期望：ELF 64-bit LSB executable, x86-64

readelf -h build/MYAPP.ELF
# 期望：Entry point 0x40000000 附近
```

### 12.4 常见的「没输出」

| 现象 | 原因 | 解决 |
|------|------|------|
| exec 后没反应 | ELF 格式不对 | `readelf -h` 检查 |
| 有 exec 但应用没输出 | printf 走串口 | 看 QEMU 串口 |
| 应用崩溃 | 栈溢出 / 段错误 | 检查数组边界、递归深度 |
| exec 返回失败 | 文件不在 rootfs | 检查 `cp` 目标路径与 8.3 大写名 |

## 十三、常见错误 FAQ

### Q1: `exec MYAPP.ELF` 提示 file not found

**原因**：ELF 没进客户机可见的 FAT 根。

**解决**：

```bash
cp build/MYAPP.ELF ../../../ToyImage/RootFs/X64/MYAPP.ELF
cd ../../../ToyImage && ./Scripts/prepare-rootfs.sh
./Scripts/run-split.sh
```

### Q2: `exec` 成功但立刻退出

**原因**：`main` 返回非 0，或一启动就崩。

**解决**：在 `main` 开头加 `printf`，看串口停在哪一步。

### Q3: `fork` 后子进程没有输出

**原因**：没 `wait`，或只看了 Shell 客户区。

**解决**：父进程 `wait(&st)`（需要退出码时用 `WEXITSTATUS(st)`）；两边 `printf` 都看串口。用 `fork` 返回值或 `getpid()` 区分父子。

### Q4: `open` 返回 -1

**原因**：路径不对，或不在已挂载卷上。

**解决**：试 `TOYOS:NOTE.TXT` 或默认卷上的 8.3 名（如 `USERNOTE.TXT`）。`ls` / `vols` 看当前卷。

### Q5: GUI 窗口创建失败

**原因**：内核窗口槽已满（最多 6 个），或未链 `libToyUi.a` / `libToyGfx.a`。

**解决**：关掉其它窗口；用 `User/Pkg/Gui` 的 Makefile。

### Q6: `socket` 返回 -1

**原因**：内核 `LWIP=0`，或 Guest 未 `lwip on`。

**解决**：`./build.sh`（默认已 `LWIP=1`）；Shell 执行 `lwip on` 后再 `exec`。

### Q7: 未知 syscall / 误调旧 GUI 号

**现象**：返回 **-38**（`-ENOSYS`）；串口可能有 `syscall: unknown`（最多约 8 行）。

**解决**：查 [`SyscallABI.h`](../../Include/SyscallABI.h)；GUI 用 `ToyUi*` / 1000+ 号，**不要**用 18/19/20/21。自测：`exec ENOSYS.ELF`。
