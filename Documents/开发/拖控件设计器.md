# 拖控件设计器

> 状态：最小可用。配套：[`布局文件格式.md`](布局文件格式.md)、[`多页面分发.md`](多页面分发.md)、应用开发指南 §5.5。  
> 目标：PC 端拖控件 → 导出 `.uitxt` → `uitxt2h` → `MyAppUi.h` → 编译进 ELF。

---

## 1. 为什么做设计器

- 学生用鼠标摆控件，少手写坐标  
- 布局仍走**编译期**生成（运行时零解析）  
- 设计器只跑 PC；ToyOS 只加载表 + 写 `OnId*`

---

## 2. `designer.py` 用法

### 2.1 运行

```text
python3 Tools/UiDesigner/designer.py
```

### 2.2 依赖

Python 3 + **Tkinter**（标准库；Debian：`python3-tk`）。无第三方包。

### 2.3 平台

Linux / macOS / Windows（有 Tk 即可）。`--help` 可在无 Tk 时打印用法。

---

## 3. 三栏界面说明

### 3.1 控件面板

Button / Label / CheckBox / TextBox：点选后进入「待放置」，画布再点一次落下（默认 80×28）。

### 3.2 画布

逻辑 **1280×720**（显示缩小）；40px 网格；选中蓝框；拖动移动；右下角改大小；Delete / 方向键微调。

### 3.3 属性栏

`id` / `text` / `x` / `y` / `w` / `h`；编辑即时刷新；未选中时禁用。

---

## 4. `.uitxt` 导出格式

与 [`布局文件格式.md`](布局文件格式.md) 一致：首行 `window "标题" 宽 高`，其后每行一控件。  
id 默认 `btn1` / `lbl1` / …，可属性栏手改。导出 `.h` 调 `uitxt2h.py`。

## 5. ToyOS 侧 `ToyUiLoadWindow`

- 头：`Include/ToyUiLayout.h`（**不**改 `ToyUi.h`）  
- 实现：`Common/Services/ToyUiLayout/ToyUiLayout.c`（Pkg `EXTRA_OBJS` 链入；**不**编进内核）  
- 按 `Kind` 调既有 `ToyUiAdd*` / `SetLabel`

## 6. 逻辑坐标与 scale

### 6.1 设计画布固定 1280×720

### 6.2 `scale ≈ 实际屏宽 / 1280`

`ToyUiScreenWidth()` 现占位 1280（README 说明；后续可接 Gui）。

### 6.3 控件坐标乘 scale

整数：`px = design * ScreenW / DesignW`。窗客户区同理。

## 7. 字体档位

约定：`Scale < 1.5` 默认；`1.5–2.5` ×2；`2.5–3.5` ×3…  
当前无公开换字号 API → 实现里留档位计算、**不**破 `ToyUi.h`。

### 7.1 公开换字 API（PR-UID-font）

- `SYS_SET_FONT_ID`(1005) → `toy_set_font_id(id)`：薄封装 `ThemeSetFontId`；改**全局**当前字（影响桌面/Shell，退出不自动恢复）。per-app 私有字仍走 PKG `font=`。
- `SYS_FONT_COUNT`(1006) → `toy_font_count()`：返回已注册字体数（id 范围 0..count-1）。
- `ToyUiFontTier(scale1000)`（`ToyUiLayout.h`）：scale(千分)→档位（1/2/3…）。只缩不放下恒为 1。

### 7.2 档位表

| scale1000 | tier |
| ---------- | ---- |
| <1500      | 1   |
| 1500–2499  | 2   |
| 2500–3499  | 3   |
| ≥3500      | 3 + (scale-3500)/1000 + 1 |

App 自决是否调 `toy_set_font_id(tier-1)`（id 与档位无强绑定，因字体 id 运行时动态注册）。

## 8. 学生工作流

1. `python3 Tools/UiDesigner/designer.py`  
2. 拖控件  
3. 导出 `.uitxt`  
4. 拷进 `CodeE-User/Pkg/UiDesigner/`（文档或写 `User/Pkg/`）  
5. `make`  
6. 填 `UiActions.c`  
7. `exec MYAPP.ELF`

---

## 9. 已知限制

- 不支持嵌套容器  
- 不支持布局引擎（绝对定位）  
- 不支持撤销/重做  
- 不支持多文档  
- 不支持样式表  
- 底栏 Button 仍受 ToyUi 物理 id 0..3 等限制
