## 5. 命名问题（目录 / 文件 / 函数 / 变量）

### 5.1 目录名

| 现状 | 结论 |
| ---- | ---- |
| 自有树几乎均为 PascalCase / `HAL` / `X64`… | **达标** |
| `HAL/RiscV/Board/milk-v-duo-s` | **例外保留**（板名） |
| `Assets/Icons/png32` 等 | 资源布局；不进本轮改名 |

### 5.2 文件名

| 现状 | 结论 |
| ---- | ---- |
| 业务 `.c/.h` 多为 `ModuleCapability.c` | **达标** |
| `Common/Fonts/*.c` 小写 | 数据文件；**不改名** |
| `HAL/X64/LwIp/toy_*.c` | 第三方适配层；**例外** |

### 5.3 函数名 — `*Init` → `*Initialize`（白名单外缩写）

公开头抽样（应迁；旧入口见规范 §2.3）：

| 符号（Include） | 建议 |
| ---------------- | ---- |
| `HalInit` / `HalSyscallInit` / `HalBlockInit` / `HalUsbInit` / `HalUsbMscInit` / `HalNetInit` / … | `HalInitialize` / `HalSyscallInitialize` / … |
| `HalVideoInitBackbuffer` | `HalVideoInitializeBackbuffer` |
| `GuiInit` / `DesktopInit` / `BlockInit` / `DbInit` / `FatInit` / `TcpInit` / `UdpInit` / `LwIpInit` / `SpinLockInit` | 对应 `*Initialize` |
| `SyscallInit` / `StoreUiActInit` | 同上 |
| 已是 `*Initialize` 的 | `SchedulerInitialize` / `ConsoleInitialize` / … **保持** |

> **策略**：按层分 PR（HalDevices → Gui/Desktop → Net/Fs），禁止一刀改完全仓。

### 5.4 函数名 — 名词+动词词序

规范：**层前缀之后先名词后动词**。存量债（示例，非全表）：

| 现状 | 更符合规范 | 风险 |
| ---- | ---------- | ---- |
| `HalGetCpuId` | `HalCpuGetId` | 三 ARCH + 调用面广 |
| `HalSetTlsBase` / `HalSetKernelStack` | `HalTlsSetBase` / `HalKernelSetStack` | 同上 |
| `HalLoadPageTable` / `HalGetCurrentPageTable` / `HalFlushTlb` | `HalPageTableLoad` / … | HAL 热路径 |
| `InitializeSerial`（若仍存） | `SerialInitialize` | 低 |
| `PickNext` / `FindFreeRun` / `HandleArp` | `NextPick` 不自然 → 宜 `RunQueuePickNext` 等**带名词前缀** | 调度/网 |
| `CopyStr` / `CopyName` / `DrawLine` | 模块内 static 帮手可随文件改 `ModuleCopyString` | 低 |
| `InitMouseOnPort` | `MouseInitializeOnPort` 或 `XhciMousePortInitialize` | 与 XHCI 拆一并 |

**注意**：`ConsoleWrite` / `SchedulerCreate` / `StoreUiOpen` 是 **模块名词 + 动词**，**合规**，勿误伤。

### 5.5 变量名

| 类 | 示例 | 结论 |
| -- | ---- | ---- |
| 局部 snake | `UI.c`：`dx_left` / `dy_top` | 应 → `DeltaLeft` 等 PascalCase（允许 `i/x/y/fd` 短名） |
| ELF 结构字段 | `p_offset` / `e_phoff` | **跟规格书**；不改 |
| 体系寄存器 | `ttbr0_el1` / `sctlr_el1` | **硬件名**；不改 |
| lwIP 类型 | `ip_addr_t` / `err_t` | **第三方**；不改 |
| 全局 | 公开 `extern` 抽查未见缺 `g` 的 Pascal 全局 | 新代码继续 `g` + PascalCase |
