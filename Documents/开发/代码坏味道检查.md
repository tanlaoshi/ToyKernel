## 1. P0（已自动检查）

### 1.1 跨层依赖

- **规则**：Common / Include / User 不得 `#include "HAL/<Arch>/Drivers/…"`；User 不得 include `Common/`/`HAL/`/`Include/`；`Common/Library/` 不得 include `Console.h`；Common / Include / User 不得有 `BOARD_` / `SOC_` `#ifdef`。
- **为什么**：破坏分层硬规则，换板/换架构会被牵连。
- **命令**：见脚本 §1.1（含排除 Documents/Build/ThirdParty/Tools 重目录）。
- **失败样例**：`Common/Services/Gui/GuiWm.c` 里 `#include "HAL/X64/Drivers/Video.h"`。
- **排除**：Documents/、Build/、ThirdParty/、Tools/Extract|Tarballs|Debs|Root。
- **修复方向**：改用 `HalVideo` 等门面；板级差异走能力旗标，不进 Common ifdef。
- **Cursor 查什么**：`在 Common/Include/User 里找所有 include HAL/.../Drivers 或 BOARD_/SOC_ ifdef`

### 1.2 魔法数字（寄存器 / 超时 / 尺寸）

- **规则**：`.c` 里出现 `0x` 后 ≥4 位十六进制，或 ≥3 位十进制，且不是命名常量（启发式）。
- **为什么**：寄存器偏移 / 超时 / 尺寸散落，改一处漏一处。
- **命令**：见脚本 1.2（排除 Fonts / FontData / PciNames / *Test*）。
- **失败样例**：`XhciWrite(0x1234, 0x10);` / `if (Try > 250) …`
- **排除**：点阵/字模、PCI 名表、测试；**已命名 `#define` 行**；`Common/Services/Theme/` 色表；脚本只印前 50 条。
- **修复方向**：提成 `#define` / `const`；寄存器用模块前缀宏（如 `XHCI_`）；USB 描述符 wValue 用 `USB_WVALUE_*`（`XHCI.h`）。
- **Cursor 查什么**：`在 Core/Common/HAL 的 .c 里找未命名的 0x???? 或三位数以上字面量，排除 Fonts`
- **已开刀**：SMELL-1…3 宏；SMELL-5 脚本剔 `#define`/Theme（柱齐 ✅ GD）。

### 1.3 忽略返回值

- **规则**：可能失败的模块调用（Fat/Block/FileSystem/Vfs/Process/Scheduler/VirtualMemory/PhysicalMemory/VfsService/Store 前缀）未 `(void)`、未赋值、未判断。
- **为什么**：错误被吞，调试时无线索。
- **命令**：见脚本 1.3；结果需人工确认（会误报如可忽略的 yield）。
- **失败样例**：`FatReadFile(Path, Buf, &Size);`
- **排除**：显式 `(void)`；返回值为 void 的函数（脚本名单含 `SchedulerIoBreath` / `StoreBe*` / `ProcessFreeSos` / `VirtualMemoryZero` 等）；`SchedulerOpsGet()->…`（取 ops 指针非忽略返回）；脚本只印前 50 条。
- **修复方向**：处理错误；或显式 `(void)` 表示有意忽略。
- **Cursor 查什么**：`找 Fat/Block/Vfs/… 调用行：既无 (void) 也没有用返回值`
- **已开刀**：SMELL-1 剔 void；SMELL-4 Core 分批；SMELL-5 脚本误报（柱齐 ✅ GD）。
