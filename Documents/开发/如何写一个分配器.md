# 如何写一个分配器

默认内核用 `MEMORY=bitmap`，源文件是 `Common/Modules/PhysicalMemoryBitmap/PhysicalMemoryBitmap.c`。学生模板在 `Student/PhysicalMemoryBestFit/PhysicalMemoryBestFit.c`，默认不链进内核。

## 你要改的函数

`MEMORY_OPS` 里真正属于政策的是：

| 函数 | 做什么 |
| ---- | ------ |
| `Init` | 清自己的状态。不要初始化锁或段表。 |
| `AllocPagesLocked` | 在段内找空闲连续页并置位；`Count==0` 或不够则返回 NULL。 |
| `FreePagesLocked` | 降引用或清位；页不在段内则警告。 |
| `RetainPageLocked` / `ReleasePageLocked` | COW 引用计数；饱和 / 未分配返回 -1。 |

调用时框架已经拿着 `gPhysLock`，函数里不要再加锁。段表通过 `PmmSegment` / `PmmLookup` 访问，不要直接碰 `gSegments`。

本模板与默认的差别在 **找空闲**：默认 first-fit（从前往后第一个够长的空洞）；模板 best-fit（在够长的空洞里选最短的）。

## 怎么编译和测试

在 `ToyKernel` 目录：

```bash
./Scripts/runtests.sh memory
make MEMORY=bestfit
```

第一条会先后断言 bitmap 与 bestfit。第二条把模板链进内核。默认的 `./build.sh` 仍然只链 bitmap。

`make MEMORY=nosuch` 会报错，这是为了避免把未知目录扫进内核。
