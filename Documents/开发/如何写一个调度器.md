# 如何写一个调度器

默认内核用 `SCHEDULER=round-robin`，源文件是 `Common/Modules/SchedulerRoundRobin/SchedulerRoundRobin.c`。学生模板在 `Student/SchedulerPriority/SchedulerPriority.c`，默认不链进内核。

## 你要改的函数

`SCHEDULER_OPS` 里真正属于政策的是：

| 函数 | 做什么 |
| ---- | ------ |
| `Init` | 清自己的计数。不要初始化锁或队列。 |
| `Enqueue` | 把任务插进当前核的队列。数字越大越优先；同级保持先来先出。 |
| `PickHome` | 任务有 `Affinity` 就返回那一核，否则轮转。 |

`Remove` 和 `PickNext` 留在框架。`Enqueue` 被调用时，这一核的队列锁已经拿着，函数里不要再加锁。

队列通过 `SchedulerRunQueueView` 拿到槽位和个数。不要直接使用 `gRunQueue`、`gTasks`、`gIdleSlot`。

## 怎么编译和测试

在 `ToyKernel` 目录：

```bash
./Scripts/runtests.sh scheduler
make SCHEDULER=priority
```

第一条会先后断言 round-robin 和学生模板。第二条把模板链进内核。默认的 `./build.sh` 仍然只链 round-robin。

`make SCHEDULER=nosuch` 会报错，这是为了避免把未知目录扫进内核。
