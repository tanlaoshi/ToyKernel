# 局域网商店与跨机聊天（NUC ↔ 台式机）

> **状态**：**规格活文档**（2026-10-01）；★ [`PR-LAN-store-1`](../路线图.md#pr-lan-store-1)；[`PR-LAN-store-0`](../路线图.md#pr-lan-store-0) **✅ TG**。  
> **场景**：同一 LAN（如 `192.168.31.0/24`）；台式机 Ubuntu 24.04；NUC 跑 ToyOS（有线 I219 / 可选 iwl）。  
> **课堂闭环（本柱目标）**：台式机既跑 **Store HTTP 仓库** 又跑 **`chatd`**；NUC 用商店 **下载 Chat**，装完立刻跟台式机文字聊天。  
> **不做**：公网 CDN、TLS、账号付费、玩具浏览器（仍见路线图远期）。

## 二、计划 1 · 台式机商店 → NUC 下载

### 2.1 目标拓扑

```text
Ubuntu 台式机                              NUC (ToyOS)
  serve-store-lan (:8080)  ──HTTP──►  store repo / sync / fetch chat
  chatd (:9090)            ◄─TCP──►  Apps/chat/CHAT.ELF（装完即聊）
```

仓库树（扁平，`file=` = URL 路径）：

```text
Build/store-lan/
  catalog.txt      # 含 chat|…|CHAT.ELF|…
  CHAT.ELF         # 收官示例（chat 入库后）
  HELLO.ELF …
```

### 2.2 台式机操作（可抄）

```bash
# ToyKernel 根；Chat 入库后 export 会带上 CHAT.ELF
./Tools/Scripts/export-store-lan.sh          # → Build/store-lan/
# ./Tools/Scripts/serve-store-lan.sh         # 导出 + :8080

cd Build/store-lan && python3 -m http.server 8080
# sudo ufw allow 8080/tcp
ip -4 addr show | grep -E 'inet '
```

### 2.3 NUC · 验通路（store-1，可用 hello）

```text
lwip dhcp
ping <台式机IP>
store repo <台式机IP>:8080
store sync
store fetch hello
store install hello
exec Apps/hello/HELLO.ELF
```

### 2.4 NUC · 收官演示（chat-4，用 chat）

```text
# 台式机已 serve-store-lan + chatd
store sync
store fetch chat
store install chat
exec Apps/chat/CHAT.ELF
# GUI/串口与台式机 chatd 互发文字
```

可选：`dbset store.repo <台式机IP>:8080`。

### 2.8 本地 + 网络双源（列表标注）

**现状问题**：`StoreLoadCatalog` 若 `StoreCache/catalog.txt` 非空则**只用网络表**，本地 `Assets/Store/catalog.txt` 从 UI 消失。

**目标**：

1. **来源可并存**：打开 Store 时同时看见「盘上预置」与「已 sync 的网络目录」。  
2. **列表注明来源**：每一行可见是 **本地** 还是 **网络**（中文短标或 `[L]`/`[N]`，以 UI 宽度为准）。

**合并规则（钉死，减少纠结）**：

| 情况 | 行为 |
| ---- | ---- |
| 仅 Assets 有 | 保留，标 **本地** |
| 仅 StoreCache 有 | 保留，标 **网络** |
| 两边同 `id` | **网络覆盖**（版本/标题以 Cache 为准），标 **网络** |
| 无任何 catalog | 仍回落内置 Builtin 表，标 **本地**（内置≈镜像预置） |

**实现要点（store-src）**：

- `STORE_ENTRY` 增 `Origin`（或 `Source`：`STORE_SRC_LOCAL` / `STORE_SRC_NET`）。  
- `StoreLoadCatalog`：先载 Assets，再载 Cache 合并覆盖，**不再**「Cache 非空则短路」。  
- `StoreUiPaint` 行格式例：`* [网] chat  Chat` / `  [本] hello Hello`（`*`=已装照旧）。  
- Shell `store list` 若有，同步带上来源（可选同刀）。  
- **不改** `catalog.txt` 文件格式（来源由路径推断，不写进文件列）。

**验收**：未 sync 全「本地」；sync 后仅网络有的包（如台式机独有 `chat`）标「网络」；两边都有的 id 标「网络」且内容为 Cache。

## 三、计划 2 · 跨机文字聊天（= Store 示例载荷）

### 3.1 角色

| 端 | OS | UI | 角色 |
| -- | -- | -- | ---- |
| 台式机 | Ubuntu 24.04 | CLI `chatd` | TCP **服务端** :9090 |
| NUC | ToyOS | GUI（可先串口）`CHAT.ELF` | TCP **客户端**；**经 Store 安装** |

### 3.2 商店包约定

| 项 | 值 |
| -- | -- |
| catalog `id` | `chat` |
| `type` | `app` |
| `file` | `CHAT.ELF` |
| 路径 | `Assets/Store/packages/chat/`（`pack-app.sh chat …`） |
| 依赖 | 无（单文件，便于 LAN fetch） |

Chat 须在 **chat-2**（或同刀）写入 catalog + packages，之后 `export-store-lan` 自动带上。

### 3.3 线协议 v0

- TCP 明文；一行一条，`\n` 结束；单行 ≤200 字节。  
- 端口 **9090**。无登录/房间。

### 3.4 ToyOS / Ubuntu 草图

- NUC：`ToyNetConnect(桌面IP, 9090)`；chat-2 串口双工 → chat-3 `ToyGfx` 日志 + 发送。  
- 桌面：`Tools/HostChat/chatd.c`（stdin ↔ socket）。

IP 传入：首期 Shell/`CHAT.CFG`/启动参数三选一（chat-0 钉死一种，建议 **启动参数或 ToyDB `chat.peer=`**）。

### 3.5 验收

| 刀 | 通过标准 |
| -- | -------- |
| chat-1 | 本机 `chatd` ↔ `nc` |
| chat-2 | ELF 能连 `chatd`；已 `pack-app` + catalog 有 `chat` |
| chat-3 | NUC 窗内可见双方文字 |
| chat-4 | **Store 下 chat → 安装 → 与台式机 chatd 互发 ≥3 行**（闭环） |

### 3.6 本柱不做

- 多房间 / 文件 / TLS / UDP  
- 内核 TtyUi 当聊天窗
