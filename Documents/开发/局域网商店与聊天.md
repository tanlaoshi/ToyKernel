# 局域网商店与跨机聊天（NUC ↔ 台式机）

> **状态**：**规格活文档**（2026-10-01）；★ [`PR-CHAT-3`](../路线图.md#pr-chat-3)；[`PR-CHAT-2`](../路线图.md#pr-chat-2) / [`CHAT-1`](../路线图.md#pr-chat-1) / [`CHAT-0`](../路线图.md#pr-chat-0) **✅ TG**；LAN 商店柱 store-* **✅**。  
> **场景**：同一 LAN（如 `192.168.31.0/24`）；台式机 Ubuntu 24.04；NUC 跑 ToyOS（有线 I219 / 可选 iwl）。  
> **课堂闭环（本柱目标）**：台式机既跑 **Store HTTP 仓库** 又跑 **`chatd`**；NUC 用商店 **下载 Chat**，装完立刻跟台式机文字聊天。  
> **不做**：公网 CDN、TLS、账号付费、玩具浏览器（仍见路线图远期）。

### 2.8 Store 目录布局 + 本地/网络双源（**store-src**）

> **钉死（2026-10-01）**：废 `Assets/Store` + `StoreCache` 双轨；**一卷根 `Store/`** 管本地源；网络 **只 sync 目录**，装包 **直达 `Apps/`**（不落盘缓存 ELF）。

#### 2.8.1 仓库树（ToyKernel 与 Guest 对齐）

```text
ToyKernel/
  Assets/          # 图标/字体/…（不再含商店）
  Store/           # ← 从 Assets/Store 整夹挪出，与 Assets 同级
    catalog.txt
    packages/<id>/ # PKG.TXT + ELF + 可选 Assets/
    README.md …

Guest 卷根（U 盘 / RootFs）：
  Store/           # 本地源（prepare 从 ToyKernel/Store 同步）
    catalog.txt
    packages/…
  Apps/<id>/       # 已安装运行副本（唯一「已装」落点）
  # 删除：Assets/Store/ 、StoreCache/ 、空壳旧 Store（若仍在）
```

`export-store-lan.sh` / `pack-app.sh` / `build.sh` prepare 一律改认 **`ToyKernel/Store`** → Guest **`Store/`**。

#### 2.8.2 三种「怎么进商店」

| 来源 | 怎么来的 | Store GUI | 来源标 |
| ---- | -------- | --------- | ------ |
| **镜像预置** | prepare 写入 `Store/packages/<id>/` + catalog，并 **写 `si.*` 注册**、同步落到 `Apps/<id>/` | **已安装** | **本地** |
| **手拷本地** | 用户往 `Store/packages/`（或扁平约定）直接拷包；**未**走注册 | **未安装**（可一键 install） | **本地** |
| **网络** | `store sync` 只更新**远程目录表**（内存 / ToyDB / 如 `Store/remote.cat`）；`store install <id>` 时 HTTP **直装进 `Apps/`**（校验在内存缓冲，**不**再写 Cache ELF） | 未装→已装 | **网络** |

要点：

1. **不要 `StoreCache/`**：网络包不「先缓存再装」；装完只在 `Apps/`（font→`Assets/Fonts/`，asset→`Assets/Packs/` 照旧）。  
2. **`sync` = 目录**：知道远端有哪些 id/标题/file；不批量拉 ELF。  
3. **预置 = 已注册已装**：与「U 盘随手拷进 `Store/`」区分开——后者标本地但显示未安装，须 `store install`。  
4. 列表 **本地 + 网络可并存**；同 `id`：**网络目录项覆盖展示元数据**，标「网络」；已装状态仍看 `Apps/`+`si.*`。

#### 2.8.3 列表行（UI）

例：`* [本] hello  Hello` / `  [本] myapp  MyApp` / `  [网] chat  Chat`  
（`*`=已装；`[本]`/`[网]`；手拷未注册无 `*`。）

#### 2.8.4 相对现状（迁移）

| 旧 | 新 |
| -- | -- |
| `ToyKernel/Assets/Store/` | `ToyKernel/Store/` |
| Guest `Assets/Store/` | Guest `Store/` |
| Guest `StoreCache/` | **删除**；远程表另置（见上） |
| `store fetch` → Cache 再 `install` | **可废弃 fetch** 或令 `install` 内联下载；文档以 install 为准 |
| sync 整表盖掉本地 catalog | **合并**；标来源 |

#### 2.8.5 验收（store-src）

| 项 | 通过 |
| -- | ---- |
| 路径 | 仓库与 Guest 均无 `Assets/Store`、`StoreCache`；有 `Store/catalog`+`packages` |
| 预置 | 开机 Store GUI：预置 id **已安装** + **本地** |
| 手拷 | 只拷进 `Store/packages/<新id>/`（或约定路径）→ GUI **未安装** + **本地**；`store install` 后变已装 |
| sync | 只更新远程目录；盘上无「网络 ELF 缓存目录」 |
| 网装 | `store install <仅远端有的 id>` → `Apps/<id>/` 可 exec；标 **网络** |
| 回归 | QEMU `10.0.2.2:8080`；`export-store-lan` 仍从新 `Store/` 导出 |

## 三、计划 2 · 跨机文字聊天（= Store 示例载荷）

> **PR-CHAT-0 冻结**（2026-10-01）：本节协议 / 端口 / 角色 / 商店 id / 对端配置 **已钉死**；chat-1+ 只实现，不改语义。

### 3.1 角色

| 端 | OS | UI | 角色 |
| -- | -- | -- | ---- |
| 台式机 | Ubuntu 24.04 | CLI `chatd` | TCP **服务端** 监听 **`:9090`** |
| NUC | ToyOS | 先串口、后 GUI `CHAT.ELF` | TCP **客户端**；**经 Store 安装**（id=`chat`） |

课演示固定一种 L2（有线 **或** Wi‑Fi）；Wi‑Fi 关联会覆盖有线 `gNicL2`。

### 3.2 商店包约定（字段预留）

| 项 | 值 |
| -- | -- |
| catalog `id` | `chat`（**唯一**商店 id） |
| `type` | `app` |
| `version` | `1`（首版；日后可 bump） |
| `file` | `CHAT.ELF` |
| `sha256` | `-`（首版可跳校验）或实算 |
| `arch` | `x86_64` |
| `title` | `Chat` |
| `depends` | **无**（单文件，便于 LAN fetch） |
| 源码包路径 | `Store/packages/chat/`（`pack-app.sh chat …`） |

**预留 catalog 行**（chat-2 写入真文件前勿当 export 硬依赖）：

```text
chat|app|1|CHAT.ELF|-|x86_64|Chat
```

Chat 须在 **chat-2**（或同刀）写入 `catalog.txt` + `packages/chat/`，之后 `export-store-lan` 自动带上。

### 3.3 线协议 v0（冻结）

| 项 | 约定 |
| -- | ---- |
| 传输 | TCP **明文** |
| 端口 | **9090**（仅此端口；无 TLS / 无第二端口） |
| 帧 | **一行一条**，以 `\n`（LF）结束；无 `\r` 要求（容忍对端 `\r\n` 时剥 `\r`） |
| 单行上限 | **≤200 字节**（含 UTF-8 文本；超长丢弃并记日志） |
| 会话 | 无登录 / 无房间 / 无心跳帧；连接即聊，断开即止 |
| 编码 | UTF-8；首期可用 ASCII |

双向对称：客户端与 `chatd` **同一行文法**，无角色前缀（谁发谁收皆裸文本行）。

### 3.4 对端 IP 配置（冻结一种）

**权威来源：ToyDB 键 `chat.peer`**

| 项 | 约定 |
| -- | ---- |
| 键 | `chat.peer` |
| 值 | `A.B.C.D` 或 `A.B.C.D:端口` |
| 默认端口 | 省略时 **9090** |
| 例 | `chat.peer=192.168.31.124` → `192.168.31.124:9090` |
| 写入 | Shell `dbset chat.peer …`（与 `store.repo` 同路）；chat-2 启动时 `DbGet` |
| 缺省 | **无默认对端**——未配置则串口提示并退出（避免误连） |

**禁止**（v0）：启动参数三选一、`CHAT.CFG` 旁路、未写回 ToyDB 的临时 peer。  
chat-2 实现：`ToyNetConnect(peer_ip, peer_port)`；串口双工。chat-3：GUI 窗内 `chat>`（DamageText + KEY，非 TextField）。

桌面侧：`Tools/HostChat/chatd.c`（stdin ↔ socket，listen `:9090`）—— **chat-1**。

### 3.5 验收

| 刀 | 通过标准 | 状态 |
| -- | -------- | ---- |
| **chat-0** | 本文 §3.1–3.4 无歧义（协议/9090/角色/id=`chat`/`chat.peer`） | ✅ |
| chat-1 | 本机 `chatd` ↔ `nc` | ✅ |
| chat-2 | ELF 能连 `chatd`；已 `pack-app` + catalog 有 `chat` | ✅ |
| chat-3 | NUC 窗内 `chat>` 双方文字 | **✅ TG** |
| chat-4 | **Store 下 chat → 安装 → 与台式机 chatd 互发 ≥3 行**（闭环） | **✅ GD** |

### 3.6 本柱不做

- 多房间 / 文件 / TLS / UDP  
- 内核 TtyUi 当聊天窗  
- 改 `STORE_HTTP_MAX`（已 256 KiB，见 store-httpmax）
