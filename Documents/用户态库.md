# ToyOS 用户态开发库

> 教学 OS 不必追完整 GNU。目标：**写用户程序够用**。排期见 [`路线图.md`](路线图.md) **1.3l** / **1.3g**；分层边界见 [`架构分层.md`](架构分层.md) §9。

---

## 1. 分层清单

### A. 必做（CRT 扩展，接现有 `User/crt/`）

| 库 / 模块 | 内容 | 备注 |
|-----------|------|------|
| **libc 子集** | `string` / `stdio`（含 `snprintf`）/ `stdlib`（`atoi`/`qsort`）/ `errno` / `unistd` / `fcntl` / `signal()` / `ctype` | ✅ **L1+L2**；非完整 POSIX |
| **libtoyos** | 稳定 syscall 包装 + 版本宏；`#include <toyos/syscall.h>` / `<toyos/version.h>`；静库 `User/Library/ToyOs/libtoyos.a` | ✅ **L1/L2**（CRT 1.1.0） |
| **目录 / stat** | `opendir`/`readdir`/`stat` | → **F4**（需 F2） |
| **libm 极简**（可选） | `sin` / `cos` / `sqrt`（表或软浮点） | 供绘图 demo |

### B. 强烈建议（应用与 GUI 课）

| 库 | 内容 | 依赖 |
|----|------|------|
| **libToyGfx** | 点/线/矩形/blit/位图（G15 先文字 damage）；字体经内核或用户态点阵 | CRT |
| **libToyUi** | 按钮/标签/列表/输入框 | libToyGfx + CRT；内核 `UI.c` 作参考 |
| **libFsUtil** | 路径、目录遍历；多卷 `TOYOS:` 前缀 | CRT；VFS 后对齐 F4 |

用户态 GUI 走 **framebuffer syscall 或窗口协议**（路线图 **G14/G15**），不直接碰 `HalVideo*`。

> **命名**：按 [`命名整改.md`](命名整改.md)，用户态库用 **`libToy*` + PascalCase 源/头**（`ToyGfx.c` / `ToyUi.h`），不用全小写 `libui`/`libgfx`。盘上演示 ELF 仍 8.3（`GUIDEMO.ELF`）。CRT 打包名 **`libtoyos.a`**（小写 os 专有名，与 `libToyUi` 并列可接受）。

### C. 按需（网络 / 多媒体课）

| 库 | 内容 |
|----|------|
| **libnet** | BSD socket 薄封装（已有 socket syscall） |
| **libjson / libini** | 配置解析（可复用 `TOYOS.DB` 思路） |
| **libpng 子集** 或自研 **BMP** | 壁纸/图标（G13 壁纸优先 BMP） |

### D. 明确后置（勿过早承诺）

完整 POSIX libc、libpthread、C++/Rust runtime、OpenGL、完整动态链接器。

## 2. 依赖关系

```text
libtoyos / CRT
  ├── libToyGfx ──► libToyUi
  ├── libFsUtil ──► libToyUi（路径/列目录）
  └── libnet
```

PR 顺序建议：**L1** ✅ → **L2** ✅（libc；dir/stat 后置 F4）→ **L3** → **L4**。

---

## 3. 与 syscall 对照（现状 → 库）

| 用户可见 API（目标） | 现有 / 计划 syscall 或内核能力 | 入库 |
|----------------------|--------------------------------|------|
| `write` / `read` / `open` / `close` | ✅ FD + 文件缓冲 | CRT / stdio |
| `printf` / `malloc` / string | ✅ CRT1/2 | CRT |
| `fork` / `wait` / `exec` / `brk` | ✅ P1～P3 | unistd |
| `pipe` | ✅ P2 | unistd |
| `kill` / 简单信号 | ✅ **P4** | signal |
| `stat` / `opendir` / `readdir` | **F2 / F4**（L2 已后置） | CRT @ F4 |
| `socket` / `bind` / `connect`… | ✅（需 `LWIP=1`） | libnet |
| `create_window` / `damage` / `poll_input` / `ui_button` | ✅ **G14/G15** | libToyUi / libToyGfx / unistd |
| 直接 `Hal*` / MMIO | ❌ 禁止 | — |

ABI 细节以 `User/include/` 与内核 `Syscall` 表为准；改号须同步本文与 CRT。

## 4. 头文件与模板（PR-L1）

| 路径 | 说明 |
|------|------|
| `User/include/*.h` | `<stdio.h>` 风格；`-IUser/include` |
| `User/include/toyos/` | `syscall.h`、`version.h` |
| `User/include/toy_syscall.h` | 兼容转发 → `toyos/syscall.h` |
| `User/Library/ToyOs/libtoyos.a` | string/printf/malloc/errno/unistd |
| `User/pkg/` | 模板：`make` → `build/MYAPP.ELF`；见 [`User/pkg/README.md`](../User/pkg/README.md) |

---

## 5. 成功标准（库侧）

- 学生能：`#include <stdio.h>`（及 `ToyUi.h`）写出程序并 `exec`。
- 模板：`User/pkg` 一条 `make` 出 `*.ELF`（**L1** ✅）。
- libc 扩展：`atoi`/`qsort`/`snprintf`/`signal`（**L2** ✅）；dir/`stat` 见 F4。
- 文档：「如何写第一个 GUI 程序」（**L3**）。
