## 1. 上电后最快验收

串口应见：

```text
Boot: I219 Flush OK
Boot: I219 IRQ=Poll
```

Shell（默认静态 `192.168.31.129` / gw `.1`，不必先 `setip`）：

```text
ping 192.168.31.1
# → reply from 192.168.31.1

lwip dhcp
# → ok ip=192.168.31.47   （具体地址随路由器）
```

备选：`net dhcp`；静态改址：`setip` / `setgw`；诊断：`net note` / `lsdev` / `show network`。

QEMU 不回归：

```bash
cd ToyImage && ./Scripts/smoke-boot.sh
TOY_NET=e1000e ./Scripts/smoke-boot.sh
```

## 2. 三句根因（后人勿重踩）

| 问题 | 根因 | 固定做法 |
| ---- | ---- | -------- |
| TX `last_rc=-3`、TDH 不前进 | 哑元冲环后 **又写满配 TCTL**，冲掉有效发送态 | **tx11**：Flush 后只保 `TCTL.EN` |
| `ping ...` 卡死 | shell **IF=0** 下 `HalCpuHalt` / 仅靠 `HalCpuTicks` | 禁 Halt；busy 循环 + `LwIpService`；`ping` 自动 `LwIpInit` |
| DHCP 无 offer | DISCOVER 仍带着静态 IP；busy 过短 | DISCOVER 前清 netif；`Budget=Ms*4000` |

序 4 各刀（含 ❌）完整表见路线图「序 4～6 刀史」——**已否假说勿再试**。
