## 0. 一句话

网卡**不另起框架**：仍是 `ToyDriverRegister` → `Probe` → `Bind` → `lsdev`。  
本柱只补 **L2 挂钩**（`NIC_L2` + `NetAttachNic`），让新人不必实现整份 `NET_BACKEND`，也不再往 `Net.c` 里塞 `gNicXxx` 特例。

```text
指南 §1～4（框架）          本范例补的（L2）
─────────────────          ────────────────
Register / Probe / Bind     NIC_L2 ops
lsdev / 命名 / ≤300         NetAttachNic
                            NetInputFrame（RX）
```

## 1. 动手前：缺口是什么

| 已有 | 缺什么 |
| --- | --- |
| 驱动框架 + Demo（D-tpl 柱） | 网卡 Bind 挂什么不清晰 |
| QEMU SLIRP + virtio/e1000 + lwIP 课路径通网 | 外人贡献第二张卡要改 `Net.c` |
| e1000 已是 `TOY_DRIVER_CLASS_NET` | 曾靠 `gNicE1000` 硬分支进协议栈 |
| `NET_BACKEND` 很胖（Ping/SendIp/…） | 新人容易以为「写网卡 = 写整份 Backend」 |

**决策（开工前钉死）**：

1. 新网卡只实现 **`NIC_L2`**（`SendFrame` / `Poll` / `GetMac`，可选 `GetLink`）。
2. Bind 调 **`NetAttachNic`**，不调 `ToyDriverNetAttach` 自造胖后端。
3. RX 统一 **`NetInputFrame`**；废除 `gNicE1000`。
4. virtio 暂留 `Net.c` 历史路径；**新卡勿仿**。
5. 切刀：`l2` → `attach` → `e1000` →（后）`addr` → `dhcp` → `doc` → `tray`。

## 2. 过程时间线（序 1～3 已落地）

### 刀 1 — PR-N-nic-l2：先立契约，不碰硬件

| 项 | 内容 |
| --- | --- |
| 动机 | 没有类型，Attach / 迁移无从谈起 |
| 交付 | `Include/DriverNic.h`（`NIC_L2`）+ `Common/Library/DriverNic.c`（`NicL2OpsValid`） |
| 纪律 | 只定义表与校验；**不**改 e1000 / Net 行为 |
| 验收 | `./build.sh`；头文件可被驱动 `#include` |

要点：`GetLink` 可为 NULL；`SendFrame`/`Poll`/`GetMac` 必须齐，否则 Attach 拒绝。

### 刀 2 — PR-N-nic-attach：协议栈开一扇门

| 项 | 内容 |
| --- | --- |
| 动机 | 有 `NIC_L2` 仍进不了栈，就还是空表 |
| 交付 | `HAL/X64/Drivers/NetNic.c`：`NetAttachNic`、`NetNicSendFrame` / `Poll` / `GetLink`；RX 仍汇入 `NetInputFrame` |
| 纪律 | 胖 `NET_BACKEND` **仍由 `Net.c` 一份**提供；`NetAttachNic` 内部再 `NetProtocolAttach()` |
| 副作用 | 去掉 `gNicE1000` 分支（与刀 3 一起收） |
| 验收 | 见路线图「逐刀验收」；`rg gNicE1000` 无匹配 |

要点：外置 NIC 只挂 L2；协议 / lwIP / Shell `ping` 路径不复制。

### 刀 3 — PR-N-nic-e1000：把活范例迁到新门

| 项 | 内容 |
| --- | --- |
| 动机 | 文档说「走 L2」必须有一份能跑的参考实现 |
| 交付 | `NetE1000.c`：`gE1000NicL2` + Bind → `NetAttachNic(&gE1000NicL2)`；`HalNetGetLinkInfo` → `NetNicGetLink` |
| 不变 | PCI Probe、E1000 环/MSI、无卡不挡桌面、`lsdev` 名 `e1000`/`e1000e` |
| 验收 | 默认 virtio `smoke-boot` PASS；`TOY_NET=e1000e ./smoke-boot.sh` PASS；可选 `ping 10.0.2.2` |

**Bind 形态（摘录）**：

```c
static const NIC_L2 gE1000NicL2 = {
    .SendFrame = E1000NicSendFrame,
    .Poll      = E1000NicPoll,
    .GetMac    = E1000NicGetMac,
    .GetLink   = E1000NicGetLink,
};

static int E1000DriverBind(TOY_DRIVER_INSTANCE *Inst) {
    (void)Inst;
    if (!E1000Ready()) {
        return -1;
    }
    return NetAttachNic(&gE1000NicL2);
}
```

## 5. 踩过的坑 / 刻意不做

| 坑或诱惑 | 处理 |
| --- | --- |
| Bind 里只 `ToyDriverNetAttach` 自造 Backend | 拒绝；协议栈只有一份 |
| 继续保留 `gNicE1000`「先跑通再删」 | 刀 2～3 一并删，避免双路径 |
| 顺手把 virtio 也迁 L2 | **不做**（历史路径；另刀再说） |
| 本柱塞 I219 / Realtek 全驱动 | **不做**（柱后薄 DID 扩可选） |
| 新文件堆过 300 行 | `DriverNic` / `NetNic` 分开；硬件仍在既有 `E1000*.c` |
| 把验收只写在聊天里 | 路线图「逐刀验收」+ 指南 §7 |

## 6. 后人怎么复用这套过程

写**任意新 PCI 网卡**时，按本柱学到的顺序：

1. 确认框架五步（指南 §2）能 `lsdev` 见到名字。  
2. 填 `NIC_L2` 四指针（`GetLink` 可空）。  
3. Bind：`NetAttachNic(&gXxxNicL2)`。  
4. RX：硬件收包路径调 `NetInputFrame`。  
5. `./build.sh` + 对应 QEMU 后端 `smoke-boot`；课路径 `ping 10.0.2.2`。  
6. **禁止**改 `Net.c` 加芯片特例。

地址可配 / DHCP 属协议栈（序 4～5，已交付）；任务栏托盘 → 序 7。**不属于**「再写一个驱动」本身。
