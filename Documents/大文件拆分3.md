## 四、硬约束（继承前轮）

1. **不改对外 API**；可新增 `*Priv.h` / 内部头。  
2. **不改逻辑 / 宏值 / 结构体布局**；禁止「拆文件顺便修 bug」。  
3. **每 PR 一块**；build + smoke；GUI/输入相关建议 NUC 点验。  
4. **全局 / BSS**：定义落最相关 `.c`；**勿为瘦文件跨 TU 搬 DMA 环**（XHCI 教训）。  
5. **勿与功能刀混 PR**（装机 / 网卡 DID / 新特性另开）。  
6. 原 `static` 跨文件 → 去 static + 内部头声明（前缀防污染）。
