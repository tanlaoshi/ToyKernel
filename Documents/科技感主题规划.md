## 一、目标与硬约束

**目标**：在保留默认「经典」浅色主题的前提下，新增一套 **tech**（深青黑底 + 青蓝强调 + 品红警告）配色，覆盖桌面 / 任务栏 / 开始菜单 / 窗框 / Shell / 控件 / 图标回退色。

| # | 硬约束 |
| - | ------ |
| 1 | **不改**现有默认主题观感（`theme=default`） |
| 2 | **不改** `Theme.h` 现有函数**签名**（允许**新增** getter） |
| 3 | **不**引入新主题引擎；复用 `TOYOS.DB` + `THEME.CFG` |
| 4 | **不**引入 TTF / 新位图壁纸（纯色；渐变可选、第 3 刀） |
| 5 | 新 `.c` ≤300 行；每刀可 `./build.sh` + `smoke-boot` |
| 6 | **不破坏**现有 Settings 桌面/Shell 色块切换 |
| 7 | **不改** UI 布局与绘制算法（只换色值来源） |

**实现选型：方案 A**（内置两套色板，DB 键 `theme=default|tech` 切换）。  
不采用方案 B（全色逐键 dbset）——键爆炸、难维护。  
方案 C（内置 + 单键覆盖）可后置：现有 `desktop` / `shell` 覆盖继续有效。

### 2.3 颜色如何定义

- **可持久化、可 Settings 改**：`gDesktopBg` / `gShellClientBg`（及 `gWallpaper`），初值来自 `COLOR_*`，可被 Load 覆盖。
- **窗框 / 任务栏 / 控件**：多数 getter **直接 `return COLOR_*` 或字面量**（如 `ThemeWindowTitleFocus → COLOR_BLUE`），**不进 DB**，换主题时必须改这些 getter 的分支（读 `gThemeId`）。
- **`UI.h` 的 `COLOR_*`**：全局常量；**禁止为本主题改这些宏**。

### 2.4 `ThemeLoad` / `ThemeSave`

```
ThemeLoad：
  优先 TOYOS.DB：ApplyDbKey(desktop|shell|font|mode|scale|fade|wallpaper|theme)
  若 DB 全无 → 读 THEME.CFG 全文 Parse
  （mode 可再从 CFG overlay）
  若 gThemeId==tech → ThemeTechApplyDefaults（套色板底色、wallpaper=0）

ThemeSave：
  写 THEME.CFG（供 ToyBoot edid / mode）+ DbSet 同名键（含 theme=）
```

路径：`ThemeCfg.c` / `ThemeParse.c` / `ThemeSave.c`。

### 2.5 主题相关 DB / CFG 键（现状）

| 键 | 含义 | 进 CFG | 进 DB |
| -- | ---- | ------ | ----- |
| `desktop` | 桌面纯色 `RRGGBB` | ✅ | ✅ |
| `shell` | Shell 客户区底色 | ✅ | ✅ |
| `font` | 字体 id | ✅ | ✅ |
| `mode` | `WxH` 分辨率偏好 | ✅ | ✅ |
| `scale` | UI 缩放 50/100/150/200 | ✅ | ✅ |
| `fade` | 窗淡入帧数 | ✅ | ✅ |
| `wallpaper` | `0|1` 是否铺 WALL.BMP | ✅ | ✅ |
| **`theme`** | **本柱新增：`default` \| `tech`** | ✅（建议） | ✅ |

**没有** `shell_bg` / `shell_text` / `win_bg` 等细键（任务书里的举例与现状不符）。第 1 刀只加 **`theme=`**，细色仍由色板表驱动。

### 2.6 `THEME.CFG` 格式（样例）

```
desktop=404040
shell=c0c0c0
font=2
mode=1920x1080
scale=100
fade=6
wallpaper=1
theme=default
```

- 一行一键；`#` 注释；颜色 6 位 hex；`mode=WxH`。  
- Boot 主要关心 **`mode=`**；色值以 Guest 内 Theme + DB 为准。

## 四、方案 A 设计要点

```
gThemeId = THEME_ID_DEFAULT | THEME_ID_TECH   // 或 strcmp("tech")

ThemeWindowTitleFocus() {
  if (gThemeId == TECH) return TECH_TITLE_FOCUS;
  return COLOR_BLUE;   // classic 行为不变
}

ThemeLoad: 解析 theme=default|tech
ThemeSave: 写 theme=
ThemeSetThemeId / ThemeThemeId   // 仅新增，旧 API 不动

切换 tech 时：
  - 可将 gDesktopBg / gShellClientBg 设成 tech 默认底色（若用户未单独改过，或强制套用一次）
  - wallpaper：建议 tech 默认 wallpaper=0（纯色）；保留用户 wallpaper 键优先
```

与现有 Settings「桌面色 / Shell 色」关系：

- `theme=tech` 决定**整套** chrome / 控件默认色。  
- `desktop` / `shell` 仍可覆盖**两处底色**（不删该能力）。  
- 第 3 刀 Settings 增加 **Theme: Default | Tech**，与色块列表并存。
