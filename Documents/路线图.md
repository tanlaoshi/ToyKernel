# ★ 开机日志柱 <a id="pr-boot-log"></a>

> **目标**：优化开机画面与 bring-up 可观测性——ToyBoot **只走串口**；设分辨率后清屏；Kernel **早启串口**、**不再清屏**，与 Boot 留下的黑屏连续滚屏；串口/屏幕同文（video 就绪前仅串口）；总开关 + 模块开关。  
> **规格**：[`开机日志规划.md`](开机日志规划.md)。  
> **状态**：**柱已收官**（细表 §七 `【归档】开机日志柱`）。下列为验收对照；**不再**占文首 ★。

| 序 | PR | 需求 | 交付 | 状态 |
| -- | --- | ---- | ---- | ---- |
| 0 | **PR-BOOT-log-doc** | j | [`开机日志规划.md`](开机日志规划.md)：出口分层 + 开关矩阵 + 缺口/目标架构 | ✅ TG `df532a2` |
| 1 | **PR-BOOT-log-uart** | a+b+c | **ToyBoot**：`UefiMain` 最前初始化 COM1；首两行串口单独一行 `ToyBoot`、再一行 `COM1 Serial OK`（ASCII；勿中文）；其后按函数块（`GetAndSetVideo` / 读 ELF / `JumpToKernel` 等）打关节点到串口；**取消** bring-up 依赖 ConOut；**SetMode/确认分辨率后清屏**（黑帧），再 `JumpToKernel`；新 API 用 `*Initialize`（勿 `*Init`）；`BootHandoff.h` 进 ToyBoot 本树 | ✅ TG Boot `bf4e2c1` / case `d7e76f2` / CRLF `e001dde` |

| 3 | **PR-K-log-cont** | e+f+g+i | 去掉跳转后/video 初始化的全屏清屏（保留 Boot 已清的黑底）；GOP 启动日志连续上滚、不重置「半截屏幕」；video 就绪后 **串口与屏幕同文**；video 就绪前仅串口 | ✅ TG `75dac0b` |

### 逐刀验收（摘要）

> QEMU 每刀；NUC 按上表两刀一波。

| PR | 验收要点 |
| -- | --- |
| **doc** | 表列：出口符号、默认开/关、落点（UART/GOP/Shell）；与代码 `rg` 可对上 |
| **uart(Boot)** | 串口见 `ToyBoot` / `COM1 Serial OK`；块关节点齐全（`Boot:` + PascalCase）；设分辨率后屏为黑；ConOut 无 bring-up 刷屏 |
| **uart(Kernel)** | 串口紧接 Boot 后续见 `ToyKernel` / `COM1 Serial OK`；无「先 GOP 后才 COM1 ok」倒置 |
| **cont** | 跳转后屏上日志接在黑底上滚，无闪黑重开；串口与屏同文（Mute 除外） |
| **geom** | 3840×2160 启动日志可用大部分高度/宽度，不再卡在约 40 行 |
| **switch** | 总关/模块关可分别静音 UART 或屏幕；默认课堂路径仍双路可见 |
