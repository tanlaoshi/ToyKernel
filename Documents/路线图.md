## 【归档】阶段 2：进程隔离 ✅


| 组件                    | 文件                                        | 内容                                              |
| --------------------- | ----------------------------------------- | ----------------------------------------------- |
| 独立页表                  | `VirtualMemory.c`                         | `VM_ADDR_SPACE`、`SpaceClone`                    |
| ELF 加载                | `Elf.c`、`Process.c`                       | 静态 `ET_EXEC`；`DT_NEEDED` + `JUMP_SLOT` 简易 `.so` |
| fork/wait/yield       | `Scheduler.c`、`Syscall.c`                 | **COW**；`wait` 可 `WNOHANG`                      |
| open/read/write/close | `Syscall.c` + 每任务 FD                      | 打开读入缓冲；close 刷盘                                 |
| 用户程序                  | `hello`/`count`/`fork`/`waitnh`/`dyndemo` | + `LIBTOY.SO`                                   |


**验证**：

```
toyos> exec FORK.ELF / SYSHELLO.ELF / SYSFORK.ELF / WAITNH.ELF
toyos> exec DYNDEMO.ELF   # 需 LIBTOY.SO
toyos> exec CAT.ELF / WRITE.ELF
toyos> ps
```

- **COW fork**：共享用户页 + `PTE_COW`；`#PF` 拆分；`PhysicalMemoryRetain/Release`
- **WNOHANG**：`SYS_WAIT` 的 `rdi`；有子进程无僵尸时返回 `0`
- **动态库**：`DT_NEEDED` → `USER_SO_BASE`；`R_X86_64_JUMP_SLOT`
- **PR-SC1**：`syscall`/`sysret` 与 `int 0x80` 解耦

- Common FAT / VFS **不动**；课堂默认仍 IDE+ATA；`TOY_DISK=ahci` → QEMU `ich9-ahci`
- 串口 `boot: ahci drives=N`；挂卷后 `ls` / `cat` / `exec` 与 IDE 路径同形
- **未做**：NVMe、USB MSC（U 盘大容量需另刀）；笔记见 [`HAL/X64/NOTES-UEFI-PC.md`](../HAL/X64/NOTES-UEFI-PC.md)

**验证**：

```
cd ToyKernel && ./build.sh
cd ../ToyImage && ./smoke-boot.sh                 # IDE 回归
TOY_DISK=ahci ./smoke-boot.sh                     # boot: ahci + ToyOS ready
# 真机：SATA/AHCI 上 FAT 含 TOYOS.ID → Shell ls / exec HELLO.ELF
```

- **`HAL/RiscV/Board/milk-v-duo-s/`**：`README` / `BoardConfig.h` / `Board.c` / `NOTES`（厂商默认固件 = C906，故落 RiscV 而非 Arm64）

- Startup：板级 `KERNEL_LOAD` / `RAM_*`；无 FB 跳过 ramfb；横幅 `board: milk-v-duo-s`

- Common：仅 `ConsoleSerialRun` 按 `HalPlatformVirtConsole` 区分文案（能力旗标，非板名 `#ifdef`）

## 【归档】PR-H2：真机键盘（xHCI 普查 + PS/2 fallback）✅

- `XHCI.c`：CCS 端口普查；优先 HID boot keyboard `3/1/1`；失败 `Disable Slot` 试下一口；要求中断端点成功（去掉假 GET_REPORT）
- `InputXhci.c`：多 xHCI 控制器试 BAR + 映射；MSI 失败仍 Bind，`Poll` 排空事件环
- `InputPs2.c`（`ps2-kbd`）：i8042 轮询；仅当 Input 未绑定时生效；注册于 `HalDriverRegister`
- 笔记：[`HAL/X64/NOTES-UEFI-PC.md`](../HAL/X64/NOTES-UEFI-PC.md) H2 节
- **未做**：hub / EHCI / 方向键全集 / IOAPIC

**验证**：

```
cd ToyKernel && ./build.sh
cd ../ToyImage && ./smoke-boot.sh
# 串口含 boot: xhci-hid keyboard（QEMU usb-kbd）；lsdev 见 xhci-hid
# 真机无 USB 键盘时可走 ps2-kbd（串口 boot: ps2-kbd keyboard）
```

## 【归档】PR-H3：无 COM1 → GOP 控制台 ✅

- 笔记：[`HAL/X64/NOTES-UEFI-PC.md`](../HAL/X64/NOTES-UEFI-PC.md) H3
