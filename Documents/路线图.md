## 1.2c 跨架构可运行 + 用户态成系统（已收尾）

> **一句话**：换 arch 还能在 QEMU `virt` 里看见 ToyOS 活着（进模块表子集、能打几条串口命令）；同时 Common 把用户程序做成更像小 Unix 的一套（`execve` + 管道 + `brk`；验收走已有 FAT 的 x86 桌面）。
>
> **Boot**：x86 继续 UEFI + ToyBoot；Arm64 / RiscV 自有 Boot（virt + DTB / OpenSBI `-kernel`）+ HAL 内 virtio/ramfb。A8/A9 的 QEMU `-kernel` 即入口。相同 GUI = Common Gui。

**做**

- **柱 1 跨架构**：A8/A9 ✅（virt 子集 + 串口 `help`/`mem`/`ps`/`halt`；`-kernel` 即入口）。
- **柱 2 用户态**：P1～P3 ✅（`execve` / 管道 / `brk`）。验收：现有 x86 FAT 路径。virt 本阶段不做 exec 是因为无块设备（A9 无盘），不是因为 P 绑架构。架构差走 `HalFrame`* / `HalElfMachine`（A2/A4），不进 syscall 的 `#ifdef x86`。

**不做（本阶段明确排除）**

- Arm/RiscV 自有 Boot 补全、HAL 内 ramfb/virtio-gpu / virtio-blk（已迁 **1.2d**）
- 真机、NVMe/AHCI、安装器
- 真 SMP / `HalSmp*`（virt 单核）
- 完整 POSIX、`mmap`、信号全集、swap
- virt 上用户 ELF / FAT（1.2c 无块设备就不做 `exec`；有盘见 **1.2d V4**）

## 1.2d 各 Arch 自有 Boot + virt 同一套桌面（已收尾）

> **一句话**：换 arch 在 QEMU 窗口里看见和 x86 同一套 Gui。
>
> **Boot**：x86 继续 UEFI + ToyBoot；Arm64 / RiscV 自有 Boot（Arm：virt + DTB；RiscV：OpenSBI `-kernel`）→ `HAL/<Arch>/Startup` 填 `BOOT_INFO`。亮屏 / 键鼠 / 盘 = **该 Arch HAL**（ramfb 或 virtio-gpu、virtio-input、virtio-blk），再接 **Common** FAT / Gui。验收脚本是 `run-virt-arm.sh` / `run-virt-riscv.sh`。

**做**

- **柱 1 自有 Boot**：V1 ✅（Arm64 DTB / RiscV OpenSBI → `BOOT_INFO`；`-kernel` 入口）。
- **柱 2 HAL 显示**：virt ramfb 或 virtio-gpu → `HalVideo`；桌面验收时 QEMU **有窗口**（不要只靠 `-nographic`）。
- **柱 3 HAL 输入**：virtio-input 或 virt 键盘，够点桌面 / 打 Shell。
- **柱 4 HAL 块设备**：virtio-blk → 已有 Common Block/FAT；virt 上也能 Theme / Files / `execve`（P1 已是 Common）。
- **柱 5 Gui 模块子集**：按 `[结构说明.md](结构说明.md)` 第 2 节顺序跑 `serial → … → video → fs → gui`（不绑 x86）。A8 串口子集可留作无头冒烟。
- **柱 6 验收脚本**：V6 ✅（`run-virt-*.sh` 默认窗口+盘；`--headless` / `smoke-virt.sh`；非 ToyImage / OVMF）。

**不做（本阶段明确排除）**

- 真机、NVMe/AHCI、安装器
- 完整 POSIX、`mmap`、信号全集、swap
- TTF / 完整 Unicode、`UI.c` 全面接入
- 真 SMP / `HalSmp*`（virt 仍单核）

## 1.2e virt 三架构对齐 x86 能力（已收尾）

> **一句话**：1.2d 已经让三架构在 QEMU 窗口里看见同一套 Gui；本阶段把 **还差的 x86 可讲能力** 补到 virt——网卡、FAT 大文件、Settings/Files 能当控件课、用户态一刀简单信号。不是重做 V1～V6，也不是把 GUI / 网络 / 硬盘 / libc 四条产品线一次铺开。
>
> **Boot**：x86 继续 UEFI + ToyBoot；Arm64 / RiscV 自有 Boot。网卡 = 该 Arch HAL 的 **virtio-net-device（MMIO）**，接已有 Common `HalNet`* / `Udp` / `Tcp`；不是把 x86 `virtio-net-pci` 搬进 Common。GUI 浅接入走 **Common** `UI.c`。信号走 Common syscall，不绑 arch。

**做**

- **柱 1 virt 网**：N9 ✅ HAL virtio-net → N10 ✅ `gModulesVirtDesktop` 挂 `net` + 脚本 + `ping`。x86 默认仍 `LWIP=0`（builtin 课）；文档写清 `LWIP=1`，不强改默认。DNS 不做。
- **柱 2 FAT**：FS3 ✅ 写上限 **8MiB**；覆盖写先新链再就地改 SFN；Shell `wrbig` 约 2MiB 验收。
- **柱 3 桌面可讲**：G11 ✅ `UI.c` 浅接入 Settings/Files（边框 / 空状态 / 焦点行）。不是全面控件化、不是 TTF。
- **柱 4 POSIX 下一步**：P4 ✅ 简单信号（`kill` + 默认终止）。择一不做 `mmap`。

**不做（本阶段明确排除）**

- 真机、NVMe/AHCI、安装器
- TTF / 完整 Unicode、`UI.c` 全面控件化 / G10 L1 全拆分
- 真 SMP / `HalSmp*`（virt ✅ **1.2f A14**；shell/gui 仍钉 BSP）
- 完整 POSIX、`mmap`、信号全集（`sigaction` / mask / 停止作业）、swap
- DNS / 更完整 socket 错误码
