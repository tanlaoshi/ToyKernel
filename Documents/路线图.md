### 1.3c x86 真机 / 桌面 PC（规划拆分）

> **一句话**：下一步全面真机 = **x86 UEFI PC / 笔记本**。先对齐课堂桌面——**亮 GOP + 键盘 + 从 FAT 读 ELF**；网卡 / NVMe / 真机 SMP 可后。真机差异全在 **HAL**（[`架构分层.md`](架构分层.md)）：Common FAT / Gui / VFS **不动**。  
> **状态**：规划 / 未实现（⬜）。只记切片，不在此开仓挡 **F2 ∥ D2**。  
> **与 1.3b**：Duo S 命令行已在 **B0–B3**；**不要**和本柱混成一个 PR。

#### 手机：明确不做 / 远后置

**Google Pixel 8（Tensor G3）**：可预见的教学周期内 **不现实**。Android AVB、bootloader 常锁；即便解锁仍是 GKI + vendor 模块 + TrustZone，没有公开 GOP、没有 virtio、存储是 UFS、显示是 MIPI DSI、USB 是 gadget 不是 COM1。早期 `printk` 也没有简单 UART，除非工厂夹具。这是数年级的 SoC OS 移植，不是一个周末的 HAL。

**小米 Mix 2（SD835 / MSM8998，2017）**：历史上略松（可解锁、有 LineageOS 社区），但 **仍不能**当作 ToyOS 下一靶。高通启动链是 PBL/XBL/ABL，专有 hypervisor、UFS、MDSS。爱好者路径是「先 Linux 再改内核」，不是把 `ToyKernel.elf` 丢进去就跑。UART 测试点或许能找，相对 UEFI PC 仍是数月 bring-up。

**结论**：手机当作「**明确不做 / 远后置**」，以免以后再问。下一步全面真机只走 **x86 UEFI PC/笔记本**。手机 **不进 B 系列、不进 H 系列**。

#### 当前 x86 与真机缺口

课堂 x86 已是 OVMF + ToyBoot GOP + ATA PIO + xHCI + virtio-net-pci + COM1 + 演示级 SMP。真 PC 上常见缺口：

| 面 | QEMU / 课堂现状 | 真机常见情况 | 本柱怎么切 |
|----|----------------|-------------|------------|
| 存储 | ATA PIO `0x1F0` | 多数机是 AHCI / NVMe，不是遗留 IDE | **H1** 第二 Block 后端；Common FAT 不动 |
| 网卡 | virtio-net-pci | e1000 / Realtek / Intel 等 | **H4** 可选后置，**不挡**桌面 |
| 串口 | COM1 `0x3F8` | 常无 0x3F8；或仅 USB-UART | **H3**；可先 GOP 控制台 |
| 中断 | 8259 路径；IOAPIC 已后置 | 真机 SMP 要 IOAPIC | **仍后置**（不进本柱） |
| USB | xHCI；PCI 扫到则可能已工作 | 机箱 xHCI 型号杂 | **H2** 普查；键盘优先 |
| 显示 | ToyBoot 已走 UEFI GOP | 真 x86 **最佳 GUI 路径仍是 GOP** | **H0** 先验收亮屏 |
| 键盘 | USB（QEMU xHCI）或假定可用 | USB vs PS/2 | **H2**；PS/2 fallback |

#### 做

- **H0**：目标机约定——能进 UEFI、U 盘 FAT、尽量有 USB 键盘；串口可选。验收：ToyBoot 已能加载 Kernel 则 **亮 GOP**（若 GOP 在该真机已工作，文档写明已知缺口即可，不假装齐）。
- **H1**：AHCI **或** NVMe 作第二 Block 后端（`BlockRegisterBackend` / 宜接 **D2**）；Common FAT / VFS **不动**。验收：真机盘或 U 盘 FAT 上 `ls` / `exec *.ELF`。
- **H2**：真机输入——xHCI 普查 / PS/2 fallback。验收：USB 或 PS/2 键盘能开 Shell、敲命令。
- **H3**：无 COM1 时的调试策略。USB serial **后置**；本刀可先 GOP 控制台 / 屏上 log。验收：无 `0x3F8` 的机器仍能看见就绪与错误，不依赖宿主机串口重定向。
- **H4**：真机网卡（e1000 等）**可选后置**，不要挡桌面。验收：有卡才 ping；无卡桌面仍过。

#### 不做（本柱明确排除）

- 手机 SoC（Pixel / Mix / 其它 Android 机）进 H 或 B
- 与 **1.3b B0–B3** 混仓（Duo S 命令行 ≠ x86 桌面真机）
- 真机 IOAPIC / 中断路由 / 把 shell/gui 迁 AP（仍后置，同 1.4）
