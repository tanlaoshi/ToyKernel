## 三、硬约束（全轨通用）

与 [`XHCI拆分.md`](XHCI拆分.md) 对齐：

1. **不改对外 API**：`Include/*.h`、`HAL/*/Drivers/*.h` 对 Common 可见的符号语义不变（可新增内部头）。  
2. **不改逻辑 / 宏值 / 结构体布局**；禁止「拆文件顺便修 bug / 改算法」。  
3. **每 PR 只搬一块**；`./build.sh` + `ToyImage/smoke-boot.sh`（或 virt smoke）通过。  
4. **真机路径**（XHCI / Video Present / Console 帧缓冲）：合并前 NUC 点验键鼠不回归。  
5. **勿与 msc-6… 混 PR**；MSC 功能刀与搬家刀分开。  
6. **全局变量**：定义落在「最相关」的 `.c`；其它文件经内部头 `extern`。  
7. 原 `static` 跨文件 → 去掉 static 并在内部头声明（命名可加前缀避免污染）。

## 十二、推荐落地顺序（与路线图关系）

```
（现在）PR-H-msc-6…     ← 功能刀，优先
        │
        ▼
A1  PR-H-xhci-msc-split-1   ← MSC 从 Core 搬家（利于后续 msc）
B1  PR-S-shell-split-1      ← Usb/Msc 命令先拆，改 msc 少碰大文件
C1  PR-S-sched-split-1
E1 / F1 / D1 / G1           ← 按痛感穿插
A2  可选 XhciEvent
B2… 其余 Shell/Console
```

**原则**：功能刀（msc）与搬家刀错开；同一周不要既大改 claim 又搬 Core。
