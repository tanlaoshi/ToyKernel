## 一、目标与硬约束

**目标**：引入平台无关的设备列表（Core），由各 Arch HAL 枚举并 `DeviceAdd`；上层用 `DeviceFind*` / **`lsdev`（Shell）** / **设备管理器窗口（GUI）** 查看。现有驱动仍自扫 PCI，**行为不变**。

| 2 | HAL 枚举只 include 公共 `Device.h` / `Hal.h` + **本 Arch 私有** PCI/DTB 头 |

## 二、现状分析（答 8 问）

### 2.1 `PciScanUSBControllers`（`HAL/X64/PCIe.c`）

- 三层循环 Bus 0..255 / Dev 0..31 / Fn 0..7，`PciReadConfig(..., 0x00)` 取 Vendor。  
- **仅**收 Class `0x0C` / Subclass `0x03`（USB）；其它设备忽略。  
- 副作用：对匹配设备 **写 Command \|= 0x07**（IO+Mem+BusMaster）——枚举器**不应**对全总线照做，以免误开设备。  
- BAR：区分 IO vs MMIO，并处理 **64-bit BAR**（type=4 占两槽）。  
- 填入 `USB_CONTROLLER`（Bus/Dev/Fn/Type/BaseAddress/Bar[]）。  
- `Vendor==0xFFFF` 时 `continue`（未对 Func==0 提前跳过整槽）。

本柱 `HalDeviceEnumerate` **复用扫描模式与 `PciReadConfig`**，但：扫**全部**功能设备、只读配置、BAR 建议对齐现有 64-bit 逻辑；**不要**抄「全局 Enable Command」。

### 2.2 `InitializeDriver`（`Core/KernelModules.c`）

```c
HalDriverRegister();
ToyDriverProbeClass(TOY_DRIVER_CLASS_BLOCK);  /* 仅 Block；勿 ProbeAll */
```

注释：勿早 Probe Input（真机无 8042 时 PS/2 排空可能死循环）。Input/Net 由后续 `usb` / `network` 模块 Probe。

第 3 刀在此前插入：

```c
DeviceInitialize();
DeviceEnumerateAll();  /* → HalDeviceEnumerate */
HalDriverRegister();
...
```

**不**把现有驱动改成从 Device 表 Probe（兼容约束）。

### 2.3 `lsdev`

| 项 | 值 |
| -- | -- |
| 文件 | `Common/Services/ShellCommands/ShellCommandsSystem.c` |
| 函数 | `CommandLsdev`（约 283–335 行） |
| 注册 | `list devices` + 别名 `lsdev` |
| 现状 | 只列 **`ToyDriverInstance*` 已 Bound** 驱动名 + Class；无 PCI 全表；net 可附 link |

第 3 刀扩展为「Devices 表 + Bound Drivers」；实现可调 `DeviceListDump()` 以免命令体膨胀。

### 2.4 `TOY_DRIVER` 与 Match

```c
typedef struct TOY_DRIVER {
    const char *Name;
    TOY_DRIVER_CLASS Class;
    const void *Match;   /* 占位；现网不用，匹配写在 Probe */
    int (*Probe)(...);
    int (*Bind)(...);
    void (*Remove)(...);
} TOY_DRIVER;
```

- 字段名是 **`Match`**，不是 `Matches`。  
- **本柱不改**该结构；Device 绑定字段独立存在于 `DEVICE_NODE`。

### 2.5 `Hal.h` 与 `HalDeviceEnumerate` 落点

`Hal.h` 已聚合 `HalDevices.h` / Port / Serial / Video / Console。`HalDriverRegister` 在 **`HalDevices.h`**。

**建议**：在 `HalDevices.h`（经 `Hal.h` 露出）末段新增：

```c
/* 平台设备枚举：扫总线并对每个设备 DeviceAdd；由 DeviceEnumerateAll 调用 */
void HalDeviceEnumerate(void);
```

也可直接写在 `Hal.h`「平台 / 设备」小节；二选一，避免两处声明。

### 2.6 Makefile

```make
CORE_SRCS := $(wildcard Core/*.c) + Scheduler/ Process/ TaskFd/ Syscall/ VirtualMemory/
ARCH_SRCS := $(wildcard HAL/$(HAL_ARCH)/*.c) + ...
```

- `Core/Device.c` → **自动编入**。  
- 若用 `Core/Device/*.c`，须 **加一行** `wildcard Core/Device/*.c`（同拆分续惯例）。  
- `HAL/X64/DeviceEnum.c` → 已在 `HAL/$(HAL_ARCH)/*.c` wildcard，**一般不用改**。Arm64/RiscV 同理。

### 2.7 `Device.c` 行数与拆分

预估核心 API + 简单 dump ≪ 300。若 dump 格式变长：

| 文件 | 内容 |
| ---- | ---- |
| `Core/Device.c` | Init / Add / Get / Find* / Bind / Unbind / EnumerateAll |
| `Core/DeviceDump.c` | `DeviceListDump` |
| `Include/DevicePrivate.h` | `DEVICE_MAX`、内部态（仅 Core 用） |

对外只 `Include/Device.h`。

### 2.8 Core 如何调 `HalDeviceEnumerate`（不 include `Hal.h`）

任务书要求 Core 不 include `Hal.h`。做法：

```c
/* Device.c */
void HalDeviceEnumerate(void);  /* 前向声明；定义在 HAL/*/DeviceEnum.c */
void DeviceEnumerateAll(void) {
    HalDeviceEnumerate();
}
```

链接期由各 Arch 提供符号；Arm/RiscV 空实现保证全平台可链。

## 三、API 草案要点（相对任务书的补强）

任务书 `DEVICE_NODE` 缺 **PCI 位置**，但 `lsdev` 要印 `[00:1F.6]`。规划采纳时 **建议增加**：

```c
UINT8 PciBus;
UINT8 PciDev;
UINT8 PciFn;
```

（非 PCI 总线填 0；DTB 用 Name/Compatible。）

其余字段按任务书：Name / Bus / Vendor / Device / Compatible / Bar[6] / Irq / Parent / Driver / Instance / Bound。

`DeviceListDump`：输出到 `ConsoleWrite*`（或 `HalConsole*`，与现 Shell 一致）；第 1 刀可先 `DebugWrite`，第 3 刀再对齐 `lsdev` 格式。

### 4.1 产品面

### 4.2 技术约束

- Locale：`en.txt` / `zh.txt` 补齐标题与列头。  
- 与 `lsdev` **同源数据**；允许格式略简于串口 dump。

### 4.3 明确不做（GUI 首版）

- 用户态 `DEVDEMO.ELF` / 改 `libToyGfx` ABI  
- 设备树图形拓扑（父子连线）— 可后置

## 八、分析结论摘要

1. **PciScanUSBControllers**：USB-only 扫描 + 开 Command + 64-bit BAR；本柱全设备只读扫。  
2. **InitializeDriver**：Register + 仅 Block Probe；第 3 刀前插 Device Init/Enumerate。  
3. **lsdev**：`ShellCommandsSystem.c` / `CommandLsdev`；现仅 Bound 驱动。  
4. **Match**：有 `Match` 占位，无 `Matches`；本柱不改。  
5. **HalDeviceEnumerate**：加在 `HalDevices.h`（或 `Hal.h` 设备段）。  
6. **Makefile**：`Core/*.c` 与 `HAL/<Arch>/*.c` 已 wildcard。  
7. **拆分**：默认单文件；Dump 膨胀再拆 `DeviceDump.c`。  
8. **Core→HAL**：前向声明，不 include `Hal.h`。  
9. **GUI**：DEV-6 `DevicesUi`；与 `lsdev` 同源只读；对标 Settings/Files。

**路径**：实现放 **`Core/`**，不是 `Common/Core/`；GUI 在 **`Common/Services/DevicesUi/`**。

**下一步**：JX **PR-DEV-1**（GUI 排在枚举与 `lsdev` 之后）。
