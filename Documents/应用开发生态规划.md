## 一、目标

让一个**会 C 语言、但不了解 ToyOS 内核**的人，能在**30 分钟内**：

1. 拿到 SDK（当前：仓库里的 `User/include` + `User/Library` + `User/Pkg`）
2. 编译第一个 Hello World
3. 在 QEMU 上运行
4. 开始写自己的应用

**核心原则**：

- 应用开发者不需要看内核代码
- 一个 SDK 目录 + 一份指南 + 几个示例 = 可以开始
- 静态库 + 无依赖 = 符合 ToyOS 哲学

## 二、ToyOS 现在能提供什么

### 2.1 用户态可用的组件

| 类别 | 内容 | 位置 |
|------|------|------|
| **CRT** | `crt0.S` / `syscall.S` / printf / malloc / string | `User/crt/` |
| **libc 子集** | stdio / stdlib / string / unistd / fcntl / signal / ctype / errno / dirent / sys/mman | `User/include/` |
| **libtoyos.a** | CRT + libc 打包（`TOYOS_CRT` **1.3.0**） | `User/Library/ToyOs/` |
| **libToyUi.a** | 窗口 / 标签 / 按钮 / 复选框 / 列表 / 输入框（ABI **1.1.0**） | `User/Library/ToyUi/` |
| **libToyGfx.a** | 文字 damage + blit + 点/线/矩形（ABI **1.2.0**） | `User/Library/ToyGfx/` |
| **libToyNet.a** | socket 薄封装 + sockaddr + DNS（ABI **1.2.0**；内核默认 `LWIP=1`） | `User/Library/ToyNet/` |
| **libFsUtil.a** | 路径拼接 / 列目录 / 多卷 `TOYOS:`（ABI **1.0.0**） | `User/Library/FsUtil/` |
| **应用模板** | `pkg` / `pkg/gui` / `pkg/net` | `User/Pkg/` |
| **链接脚本** | `user.ld`（x86 @ `0x40000000`） | `User/` |

### 2.2 系统调用（应用可见 ABI）

**30 个 syscall（号 0–29）**，与 `Include/Syscall.h` / `User/include/toyos/syscall.h` 一致：

| 类别 | syscall |
|------|---------|
| 进程 | exit / fork / wait / execve / kill / yield / signal |
| 文件 | open / read / write / close / **lseek** / FileStat / OpenDirectory / ReadDirectory |
| IPC | pipe / dup |
| 内存 | brk / mmap / munmap |
| 网络 | socket / bind / connect / listen / accept（send/recv = 在 socket fd 上 write/read；需 `LWIP=1`） |
| 窗口 | create_window / damage / poll_input / ui_button / damage_rect |

CRT / libToy* 已包装上述能力；应用一般不必直接调 `toy_syscall`。

详见 [`技术手册.md`](技术手册.md#tm-i-layers) §7.1（**0–29**；**29=`lseek`**）。

## 三、缺口盘点

### 3.1 libc 缺口

| 头 | 已有 | 明显缺口 |
|----|------|----------|
| `<stdio.h>` | printf / sprintf / snprintf / puts / perror；**fopen / fread / fwrite / fseek / ftell / fclose**（无缓冲） | 无 stdin/stdout FILE*；**fopen("w") 不截断**（内核忽略 flags） |
| `<stdlib.h>` | malloc / free / exit / atoi / atol / abs / qsort；**realloc / calloc** | **strtol / getenv** |
| `<string.h>` | strlen / strcmp / strncmp / strcpy / strncpy / mem*；**strstr / strchr / strcat / strdup** | — |
| `<unistd.h>` | read / write / close / **lseek** / fork / wait / pipe / dup / execve / brk / kill / mmap / munmap | **getcwd / chdir / sleep / getpid**；无 libc `yield()`（用 `toy_yield()`） |
| `<fcntl.h>` | open + 标志宏 | 内核**忽略** flags |
| `<signal.h>` | signal / kill；SIGINT / KILL / TERM；教学级自定义 handler | 无 sigaction / mask / 停止作业 |
| `<ctype.h>` | isdigit / isspace / isalpha | 极小集 |
| `<dirent.h>` | OpenDirectory / ReadDirectory / CloseDirectory / FileStat（`TOY_DIR *`，非 POSIX 名） | 够用 |
| `<sys/mman.h>` | mmap / munmap；`PROT_*` / `MAP_ANONYMOUS` | 无 `MAP_FIXED` / `mprotect`；文件映射为私有拷贝 |
| `<sys/wait.h>` | ❌ 无（`wait` 在 `<unistd.h>`） | `wait(int *status)` **不按 pid 等**；CRT 目前把 `*status` 写成 0 |
| `<math.h>` | ❌ 无 | 可选 |

### 3.2 领域库缺口

| 库 | 现状 | 缺口 |
|----|------|------|
| **libToyGfx** | `ToyGfxDamageText` + `DamageRect` + 点/线/矩形（ABI **1.2.0**） | **位图** |
| **libToyUi** | CreateWindow / SetLabel / AddButton / Poll + 复选框/列表/输入框（ABI **1.1.0**） | **滚动条 / 菜单** |
| **libToyNet** | socket / connect / bind / listen / accept / send / recv；`ToyNetIpv4()`；`ToySockAddrIn`；`ToyNetResolve`（点分 / localhost / 域名） | **完整 POSIX `getaddrinfo` / 网络序 sockaddr** |
| **libFsUtil** | `FsUtilJoin` / `VolumePath` / `ListDir`（ABI **1.0.0**） | **getcwd / 递归树** |
| **libjson / libini** | ❌ 无 | 配置解析 |
| **libm** | ❌ 无 | sin / cos / sqrt |

### 3.3 缺口的优先级

| 优先级 | 缺口 | 影响 |
|--------|------|------|
| **P0** | libToyGfx 点/线/矩形封装（底层 blit 已有） | ✅ **PR-A-gfx-api** |
| **P0** | libToyUi 文本输入框 | ✅ **PR-A-ui-api**（无键盘输入；点选列表可写入） |
| **P0** | lseek / fopen 系列 | ✅ **PR-A-libc**（`SYS_LSEEK=29`；fopen 无缓冲） |
| **P1** | realloc / calloc | ✅ **PR-A-libc** |
| **P1** | strstr / strchr | ✅ **PR-A-libc** |
| **P1** | libFsUtil | ✅ **PR-A-fsutil** |
| **P2** | sockaddr 结构 | ✅ **PR-A-net-dns**（主机序 `ToySockAddrIn`；`connect(fd,ip,port)` 保留） |
| **P2** | sleep / getpid / libc `yield()` | 无延时；进程示例偏啰嗦 |
| **P2** | `wait` 填真实退出码 | 拿不到子进程 return 值 |
| **P3** | libm | 数学计算 |
| **P3** | BMP/PNG 解码 | 图片显示 |

## 四、库的提供方式

### 4.1 形态选择

| 方式 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| **静态库** | 简单、无依赖 | 体积大 | ✅ **采用** |
| 动态库 | 体积小、共享 | 需要动态链接器 + 版本管理 | ❌ 太复杂 |
| header-only | 零链接 | 编译慢、代码重复 | ⚠️ 仅限小库 |

**采用静态库**，符合 ToyOS「无依赖」哲学。

### 4.2 SDK 目标形态

```
ToySdk/                    ← 可独立分发的 SDK 目录
├── include/               ← 应用可见头（Unix CRT 名保持小写）
│   ├── toyos/
│   ├── stdio.h / stdlib.h / ...
│   ├── ToyUi.h / ToyGfx.h / ToyNet.h
│   └── ...
├── Library/               ← 预编译静态库（对齐 User/Library）
│   ├── libtoyos.a
│   ├── libToyUi.a
│   ├── libToyGfx.a
│   ├── libToyNet.a
│   └── libFsUtil.a
├── user.ld                ← 链接脚本
├── Examples/              ← 示例代码
├── Documents/             ← 开发指南
└── ToySdk.mk              ← 应用 Makefile 规则（对齐 ToyUser.mk）
```

**应用开发者只需拿到这个 SDK 目录 + 宿主机 gcc**，就能编译。当前过渡形态：直接用仓库 `User/`。

## 五、开发环境搭建

### 5.1 当前状态

应用开发者需要：

1. Linux 或 WSL2
2. gcc / ld / make；跑起来还要 QEMU（`qemu-system-x86_64`）
3. 克隆 ToyKernel，并与兄弟仓 **ToyImage**（QEMU 入口）放在一起
4. **过渡**：在 `User/Pkg/` 里写代码，用 `ToyUser.mk` 编译
5. **SDK（PR-A-sdk-pack ✅）**：`./Tools/build-sdk.sh` → `Dist/ToySdk/`，课外只带 SDK 目录
6. 复制 ELF 到 `ToyImage/rootfs/`
7. `./run-split.sh` 启动 QEMU

### 5.2 三种改进方向

| 方向 | 说明 | 落地难度 |
|------|------|----------|
| **A. 简化本地环境** | `Tools/build-sdk.sh` → `Dist/ToySdk/` | ✅ |
| **B. Docker 镜像** | `docker run toyos/dev` | 中（国内网络问题） |
| **C. Web IDE** | 浏览器里写代码 + 云端编译 | 高（1–2 月） |

**先做 A**，再做 C（B 因国内网络问题暂缓）。

### 5.3 方案 A 的目标

**一条命令产出 SDK**（已落地 `Tools/build-sdk.sh`）：

```bash
./Tools/build-sdk.sh
# 输出到 Dist/ToySdk/
```

**开发者使用**：

```bash
cd my-app/
make          # 编译出 MYAPP.ELF
make deploy   # 复制到 ToyImage/rootfs/
make run      # 启动 QEMU
```

## 八、硬约束

1. **不改内核 API 号 0–28**：现有 syscall 行为不变；本柱可**加** `SYS_LSEEK=29`。libToy ABI 向后兼容。
2. **不改现有应用**：`User/Pkg/` 下的模板保持可用
3. **静态库**：保持静态链接，不引入动态链接器
4. **不引入新依赖**：SDK 只依赖宿主机 gcc + make
5. **每 PR 独立可验证**：编译 + QEMU 跑通
6. **文档先行**：每个 PR 的文档优先于代码

### 10.2 原稿 API 速查**不可照抄**
