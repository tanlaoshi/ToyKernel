## 1. 五分钟概念

| 概念 | 含义 |
| --- | --- |
| `ToyDriverRegister` | 只把驱动放进表；**不上线** |
| `ToyDriverProbeClass` | 调 `Probe`；成功再 `Bind`；`Bound=1` 后 `lsdev` 可见 |
| Backend | Input/Block/Net 的真实 ops；真驱动在 **Bind** 里 `*Attach` |
| `Match` | 头文件占位；**现网不用**，匹配写在 `Probe` |

启动链（x86）：`HalDriverRegister()` → 早期 Probe **BLOCK** → VMM 后再 Probe **INPUT/NET**…

---

## 2. 写一个驱动（5 步）

1. **复制** `_template/Template.c` → `HAL/X64/Drivers/MyDriver.c`  
   - **不要**把文件留在 `_template/` 下指望编译。模板目录**永不**进 `Kernel.elf`。  
2. **改名**：`Name`、`Template*` / `gTemplate*` 前缀、`MyDriverRegister`。  
3. **实现 `Probe`**：有设备 `return 0`；否则非 0。模板默认 `-1`（故意不上线）。  
4. **注册**：`HAL/X64/HalDevices.c` → `HalDriverRegister()` 加一行 `MyDriverRegister();`。  
5. **验证**：`./build.sh` → `cd ../ToyImage && ./run-split.sh` → Shell `lsdev` 应见 `my-driver …`；串口有 `driver: registered=… bound=…`。

扁平 `Drivers/*.c` 会自动编入；子目录除 `XHCI/` 外不会。

## 3. 课堂 Demo（已默认开启）

| 项 | 行为 |
| --- | --- |
| 文件 | `HAL/X64/Drivers/DemoDriver.c` |
| `lsdev` | `demo-driver input` |
| Probe / Bind | 串口：`demo: probe called` / `demo: bind called` |
| Backend | **永不** `ToyDriverInputAttach`（不抢键鼠） |

关闭：

```bash
make TOY_DEMO_DRIVER=0
cp -f Build/HAL/X64/Kernel.elf ../ToyImage/Kernel.elf
cp -f Build/HAL/X64/Kernel.elf ../ToyImage/rootfs/Kernel.elf
```

或 `./build.sh TOY_DEMO_DRIVER=0`（会 clean）。换 `0/1` 后须确认 **重编了** `HalDevices`（Makefile 有 stamp）；再 **拷贝** Kernel 到 ToyImage，否则 smoke 仍是旧镜像。

## 4. Probe 怎么找设备

| 模式 | 做法 | 参考 |
| --- | --- | --- |
| A 固定口 / 地址 | Probe 内直接访问 | `InputPs2.c`、`BlockAta.c` |
| B PCI | 扫 class / VID+DID | `BlockAhci.c`、`InputXhci.c`、`NetE1000.c` |
| C 软条件 | VMM / 策略位 | `BlockMsc.c` |

`TOY_DRIVER.Match` **仍是占位**；本柱不实现表驱动匹配（可选文档见 D-tpl-4）。

---

## 5. Bind 挂哪一类 Backend

| 类 | Bind 调用 | 注意 |
| --- | --- | --- |
| INPUT | `ToyDriverInputAttach(&ops)` | **单槽**；后挂可盖先挂（xhci vs ps2） |
| BLOCK | `ToyDriverBlockAttach(&ops)` | 后端指针后挂覆盖（NVMe > AHCI > ATA） |
| NET | `ToyDriverNetAttach(&ops)` | 单槽；e1000 可盖 virtio-net |

课堂 Demo 故意不 Attach，只占实例槽给 `lsdev` 看。真驱动必须 Attach 才会驱动硬件。

`Poll` / 中断 **不在** `TOY_DRIVER` 上：填 Backend 的 `Poll`，或自接 IRQ（如 xHCI）。

## 6. 常见错误

| 现象 | 原因 |
| --- | --- |
| Register 了但 `lsdev` 没有 | 忘了 `HalDriverRegister` 调用；或 Probe/Bind 失败 |
| Probe=0 仍看不见 | Bind 返回非 0（例如 Input 已被占用且你还去 Attach） |
| 改了 `_template/Template.c` 无效果 | 模板不编进内核；必须复制到 `Drivers/*.c` |
| `make TOY_DEMO_DRIVER=0` 后 smoke 仍有 `demo:` | 未重链/未拷贝到 `ToyImage/Kernel.elf` |
| 开机卡死 | Probe 里硬件死循环；加超时 |

禁止：把 `_template/` 当真驱动目录；盲目 `Drivers/**/*.c` 把模板扫进链接。

```bash
# 模板未链入（精确符号）

  'TemplateDriver|gTemplate|TemplateProbe|TemplateBind|TemplatePoll|TemplateKbdDequeue|TemplateMousePresent|TemplateMouseDequeue|TemplateRemove'
# 期望：空

# Demo 默认开
cd ../ToyImage && ./smoke-boot.sh
# 串口应有 demo: probe/bind called；Shell lsdev 有 demo-driver
```
