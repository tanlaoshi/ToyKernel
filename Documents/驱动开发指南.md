## 1. 五分钟概念

| 概念 | 含义 |
| --- | --- |
| `ToyDriverRegister` | 只把驱动放进表；**不上线** |
| `ToyDriverProbeClass` | 调 `Probe`；成功再 `Bind`；`Bound=1` 后 `lsdev` 可见 |
| Backend | Input/Block/Net 的真实 ops；真驱动在 **Bind** 里 `*Attach` |
| `Match` | 头文件占位；**现网不用**，匹配写在 `Probe` |

启动链（x86）：`HalDriverRegister()` → 早期 Probe **BLOCK** → VMM 后再 Probe **INPUT/NET**…

---

## 2. 写一个驱动（5 步）

1. **复制** `_template/Template.c` → `HAL/X64/Drivers/MyDriver.c`  
   - **不要**把文件留在 `_template/` 下指望编译。模板目录**永不**进 `Kernel.elf`。  
2. **改名**：`Name`、`Template*` / `gTemplate*` 前缀、`MyDriverRegister`。  
3. **实现 `Probe`**：有设备 `return 0`；否则非 0。模板默认 `-1`（故意不上线）。  
4. **注册**：`HAL/X64/Hal/HalDevices.c` → `HalDriverRegister()` 加一行 `MyDriverRegister();`。  
5. **验证**：`./build.sh` → `cd ../ToyImage && ./run-split.sh` → Shell `lsdev` 应见 `my-driver …`；串口有 `driver: registered=… bound=…`。

扁平 `Drivers/*.c` 会自动编入；子目录除 `XHCI/` 外不会。

## 3. 课堂 Demo（已默认开启）

| 项 | 行为 |
| --- | --- |
| 文件 | `HAL/X64/Drivers/DemoDriver.c` |
| `lsdev` | `demo-driver input` |
| Probe / Bind | 串口：`demo: probe called` / `demo: bind called` |
| Backend | **永不** `ToyDriverInputAttach`（不抢键鼠） |

关闭：

```bash
make TOY_DEMO_DRIVER=0
cp -f Build/HAL/X64/Kernel.elf ../ToyImage/Kernel.elf
cp -f Build/HAL/X64/Kernel.elf ../ToyImage/RootFs/X64/Kernel.elf
```

或 `./build.sh TOY_DEMO_DRIVER=0`（会 clean）。换 `0/1` 后须确认 **重编了** `HalDevices`（Makefile 有 stamp）；再 **拷贝** Kernel 到 ToyImage，否则 smoke 仍是旧镜像。

## 4. Probe 怎么找设备

| 模式 | 做法 | 参考 |
| --- | --- | --- |
| A 固定口 / 地址 | Probe 内直接访问 | `InputPs2.c`、`BlockAta.c` |
| B PCI | 扫 class / VID+DID | `BlockAhci.c`、`InputXhci.c`、`NetE1000.c` |
| C 软条件 | VMM / 策略位 | `BlockMsc.c` |

`TOY_DRIVER.Match` **仍是占位**；本柱不实现表驱动匹配。细则：[`驱动匹配规范.md`](驱动匹配规范.md)（三模式 + **不强制**）。

## 5. Bind 挂哪一类 Backend

| 类 | Bind 调用 | 注意 |
| --- | --- | --- |
| INPUT | `ToyDriverInputAttach(&ops)` | **单槽**；后挂可盖先挂（xhci vs ps2） |
| BLOCK | `ToyDriverBlockAttach(&ops)` | 后端指针后挂覆盖（NVMe > AHCI > ATA） |
| NET（**协议门面**） | `ToyDriverNetAttach(&ops)` | **胖** `NET_BACKEND`（Ping/SendIp/…）；一般只由 **`Net.c`** 提供一份 |
| NET（**网卡 L2**） | **`NetAttachNic(&nic_l2)`** | **新网卡走这条**（PR-N-nic）；见下节 |

课堂 Demo 故意不 Attach，只占实例槽给 `lsdev` 看。真驱动必须 Attach 才会驱动硬件。

`Poll` / 中断 **不在** `TOY_DRIVER` 上：填 Backend / `NIC_L2` 的 `Poll`，或自接 IRQ（如 xHCI / e1000e MSI）。

## 5.1 网卡驱动（仍是 ToyDriver · 走 NIC_L2）

网卡**也是驱动**：同样 `ToyDriverRegister` → `Probe` → `Bind` → `lsdev`，遵守本指南 §2～4 与 [`开发命名规范.md`](开发命名规范.md)。

与键鼠/块设备的差别在 **Bind 挂什么**：

```text
TOY_DRIVER (Probe/Bind)          协议栈（Net.c / lwIP）
        │                              ▲
        │ Bind                         │ NetInputFrame / HalNet*
        ▼                              │
   NIC_L2  ops  ──NetAttachNic()───────┘
   SendFrame / Poll / GetMac [/ GetLink]
```

| 要写 | 不要写 |
| --- | --- |
| `NIC_L2`：`SendFrame`、`Poll`、`GetMac`（可选 `GetLink`） | 整份 `NET_BACKEND`（Ping/SendIp/FormatIp…） |
| Bind 里 **`NetAttachNic(&gMyNicL2)`** | Bind 里只 `ToyDriverNetAttach` 自造胖后端 |
| RX 路径调 **`NetInputFrame(pkt, len)`** | 改 `Net.c` 里 `gNicE1000` 式硬分支（已废除） |

**活范例**：`HAL/X64/Drivers/NetE1000.c`（PCI Probe + `gE1000NicL2` + `NetAttachNic`）。  
**头文件**：`Include/DriverNic.h`。  
**拷贝骨架（不进 Kernel）**：`HAL/X64/Drivers/_template/TemplateNetL2.c`。  
**排期 / 验收命令**：[`路线图.md` · PR-N-nic](路线图.md#pr-n-nic)。  
**开发过程（本柱怎么拆刀、踩过什么坑）**：[`驱动开发范例-网卡L2.md`](驱动开发范例-网卡L2.md)。

地址 / DHCP（协议栈侧，**不是**网卡驱动本体）：

| 能力 | 入口 |
| --- | --- |
| 静态 IP/GW/DNS | Shell `net config` / `setip` `setgw` `setdns`；`NetConfig` |
| DHCP | `lwip dhcp` / `net dhcp`；成功写回 `NetConfig`；后设静态停 DHCP |
| 课路径默认 | QEMU hypervisor：仍默认 `10.0.2.15/24` + GW/DNS SLIRP |

virtio-net-pci 仍把队列做在 `Net.c` / `NetVirtio.c` 内（历史路径）；**新 PCI/MMIO 网卡不要再仿「改 Net.c 特例」**，一律 `NIC_L2`。

## 6. 常见错误

| 现象 | 原因 |
| --- | --- |
| Register 了但 `lsdev` 没有 | 忘了 `HalDriverRegister` 调用；或 Probe/Bind 失败 |
| Probe=0 仍看不见 | Bind 返回非 0（例如 Input 已被占用且你还去 Attach） |
| 改了 `_template/Template.c` 无效果 | 模板不编进内核；必须复制到 `Drivers/*.c` |
| `make TOY_DEMO_DRIVER=0` 后 smoke 仍有 `demo:` | 未重链/未拷贝到 `ToyImage/Kernel.elf` |
| 开机卡死 | Probe 里硬件死循环；加超时 |
| 网卡 `lsdev` 有、但 ping 不通 | Bind 未 `NetAttachNic`；或 RX 未调 `NetInputFrame`；或只挂了空 `NIC_L2` |
| 新网卡去改 `Net.c` 加 `if (gMyNic)` | 违规；应 `NIC_L2` + `NetAttachNic`（见 §5.1） |

禁止：把 `_template/` 当真驱动目录；盲目 `Drivers/**/*.c` 把模板扫进链接。

## 7. 验收速查

```bash
# 模板未链入（精确符号；含 Net L2 骨架）
nm Build/HAL/X64/Kernel.elf | grep -iE \
  'TemplateDriver|gTemplate|TemplateProbe|TemplateBind|TemplatePoll|TemplateKbdDequeue|TemplateMousePresent|TemplateMouseDequeue|TemplateRemove|TemplateNet'
# 期望：空

# Demo 默认开
cd ../ToyImage && ./smoke-boot.sh
# 串口应有 demo: probe/bind called；Shell lsdev 有 demo-driver

# 网卡 L2 + 地址/DHCP（PR-N-nic）
cd ../ToyKernel && ./build.sh
cd ../ToyImage && ./smoke-boot.sh
TOY_NET=e1000e ./smoke-boot.sh
# Guest（可选手测）：
#   show network / net config
#   lwip on → ping 10.0.2.2
#   lwip dhcp → 有 offer 时非空 IP；再 setip 后 dhcp=off
```

细命令与序 4～7 验收见路线图 [`#pr-n-nic`](路线图.md#pr-n-nic)「逐刀验收」。
