## 一、目标（需求 a–k 摘要）

| 代号 | 目标 |
|------|------|
| a | ToyBoot 日志**全部走串口**；COM1 初始化放在最前；首两行：`ToyBoot` / `COM1 Serial OK`（串口全 ASCII，NUC 终端勿用中文） |
| b | ToyBoot 按当前函数分块，每块向串口打关节点 |
| c | 设完分辨率后 ToyBoot **清屏** |
| d | Jump 后 Kernel **先**初始化串口；首两行：`ToyKernel` / `COM1 Serial OK` |
| e | Kernel 日志两条路：串口 + 屏幕 |
| f–g | Boot 已清屏后，Kernel **不要再清屏**；同一黑底连续上滚 |
| h | 行列按分辨率 × 字体算满，去掉 4K「上半屏」硬顶 |
| i | video 就绪后串口与屏幕**同文**；就绪前仅串口 |
| j | 本文：盘点全部出口与开关 |
| k | 串口与屏幕各自 **总开关 + 模块开关** |

**硬约束**：不改 syscall；纯 C；QEMU + NUC；VM 上 GOP `SetMode` 防 GTK 重置逻辑可保留。

## 二、启动链路（与日志落点）

```
OVMF → ToyBoot/UefiMain
         ├─（目标）最早 COM1 SerialInitialize → 横幅 ToyBoot / [COM1]
         ├─ GetAndSetVideo →（目标）清屏
         ├─ 读 ELF / JumpToKernel（ExitBootServices 后 Print 失效）
         └─ jmp KernelEntry
              → KernelMain
                   ├─（现状）HalVideoSet + ClearScreen + GopEnable + ToyLogBoot  ← 串口可能尚未 Init
                   ├─ KernelModulesRun：serial → … → video(再 Clear) → …
                   └─ HalSerialGopMirror(0) → 调度 / 桌面
```

## 三、日志出口盘点（现状）

### 3.1 出口分层

| 层 | 符号 / 入口 | 默认落点 | 受谁开关 |
|----|-------------|----------|----------|
| ToyBoot UEFI | `Print` / `BootDbg` | ConOut（多为 GOP 文本；**无自管 COM1**） | `TOY_BOOT_DEBUG` 仅门 `BootDbg`；失败类 `Print` 常开 |
| UART 驱动 | `SerialWrite` / `SerialInitialize` | COM1 `0x3F8` | `TOY_SERIAL`（总）；未 Initialize 则空 |
| Hal 通道 | `HalSerialWriteChannel` | ring 常写；UART 按通道；GOP 仅 BOOT（及 BootMark USB） | `TOY_SERIAL_*` + `GopMute`/`GopMirror`/`VideoUp` |
| 宏 | `ToyLog*` / `ToyBootMark*` | → `HalSerialWriteChannel` / `BootMarkChannel` | 同上 |
| 调试 | `DebugWrite` / `DebugHex*` | → `HalDebugWrite` → MISC 串口 | **`TOY_KERNEL_DEBUG`**（`./build.sh DEBUG=1`） |
| 裸串口 | `HalConsoleWriteSerial` | 仅串口 | 通道/总开关间接 |
| Shell | `ConsoleWrite` | 串口 +（video 且 Shell 焦点）客户区；否则 scrollback | **不受** Kernel Debug 宏；UART 走 MISC |
| 库 | `LibWrite` | 注册 sink 或 `HalDebugWrite` | 视 sink |

### 3.2 ToyBoot（`ToyBoot/Boot.c`）

| 项 | 现状 |
|----|------|
| 串口 | **无** 16550 / SerialIo 初始化 |
| 屏幕 | 全程 `Print(L"ToyBoot: …")`（约 50+ 处；含失败） |
| 调试 | `TOY_BOOT_DEBUG`：`BootDbg`→`Print` 或空；`./build.sh DEBUG=1` |
| 清屏 | **无**（`SetMode` 后不 Blt/ClearScreen） |
| 分块 | 函数：`GetAndSetVideo` / `ReadKernelFile` / `CheckAndLoadKernel` / `GetXhciBaseAddress` / `JumpToKernel` / `UefiMain` |

**常开 `Print` 主题（非穷举）**：THEME/EDID/GOP 选型与 `display WxH`；Kernel.elf 来源/失败；ELF 错误；`loading` / `kernel loaded` / `ExitBootServices + jump`。

**仅 `BootDbg`**：模式表打分、XHCI 枚举细节、部分加载地址。

### 3.3 Kernel 串口初始化时机（现状缺口）

| 步骤 | 文件 | 行为 |
|------|------|------|
| 1 | `HAL/X64/Startup.c` → `KernelMain` | **PR-K-log-uart**：`HalSerialInitialize`（`SerialInitialize`）在 Jump 后、其它日志前；横幅 `ToyKernel` / `COM1 Serial OK`；幂等 |
| 2 | `KernelModules` 首模块 `serial` | 再调 `HalSerialInitialize`（无二次横幅）；`KernelMain`/`InitializeVideo` 不再 Clear（**PR-K-log-cont**） |
| 3 | `InitializeVideo` | 后缓冲 + 幂等 `HalSerialGopEnable`（**不**再 Clear / 顶带 Fill） |
| 4 | 模块跑完 | `HalSerialGopMirror(0)` 关 boot→GOP 镜像 |

### 3.4 HalSerial / GOP 启动日志（`HAL/X64/HalSerial.c`）

| 机制 | 行为 |
|------|------|
| ring | 通道写入常进 ring（PHOTO / `HalSerialLogText`） |
| UART | `ChannelUartOn(Channel)` ← `TOY_SERIAL_*` |
| GOP 镜像 | `ChannelGopOn`：BOOT/FS/GUI；需 `gGopMirror && gVideoUp && !Mute` |
| BootMark | BOOT/USB 可上屏上滚；UART 仍受通道约束 |
| 横幅 | 一次黄字 `"ToyOS boot"`（`GopBannerOnce`） |
| 上滚 | `BootLogScrollUp`（Ubuntu 式；保留顶栏） |
| 行缓冲 | `gLine[BOOT_LOG_LINE_MAX]`（512）；列数=`(W-边距)/FontAdvanceX`，满宽软换行 |
| PHOTO | 保留顶栏 `ToyOS boot`；读秒并入白字日志**当前行**原地刷新（无底栏黄字、无 PHOTO 横幅） |

### 3.5 Shell 几何硬顶（相关但非 boot 主路径）

| 常量 | 文件 | 值 |
|------|------|-----|
| `SB_LINES` / `SB_COLS` | `Include/ConsolePrivate.h` | 64 / 120 |
| `LINE_MAX` | 同上 | 128 |

### 3.6 高频调用方（数量级，`rg` 计数参考）

| 区域 | 代表文件 | 备注 |
|------|----------|------|
| Shell 命令 | `ShellCmdNet.c` / `ShellCmdFsUi.c` / `ConsoleCmd.c` … | 多为 `ConsoleWrite`（交互，非 boot） |
| Boot | `ToyBoot/Boot.c` | `Print`/`BootDbg` |
| USB/xHCI | `XhciCore.c` / `InputXhci.c` | `ToyLogUsb` / BootMark / Mute |
| FS / 安装 / 主题 | `FileSystem.c` / `Install.c` / `Theme.c` | `ToyLogFs` / Boot / Misc |
| Gui | `GuiPointer.c` / `GuiOpen.c` / `SettingsUi.c` | `ToyLogGui` / `DebugWrite` |
| 进程/调度 | `Process.c` / `Scheduler.c` | `DebugWrite` / Misc |

完整清单以仓库 `rg 'ToyLog|DebugWrite|Print|ConsoleWrite|HalConsoleWriteSerial|BootDbg'` 为准；改刀时更新本节日期。

### 3.7 易混概念（不是日志开关）

| 名字 | 真实含义 |
|------|----------|
| THEME `mode=WxH` | **分辨率偏好**（Boot/Theme），不是 serial+screen |
| PHOTO / Shell `mode=dual` | **xHCI dual IRQ** 诊断，不是双路日志 |
| `NO_COM1=1` | 构建兼容名，等价 `SERIAL=0` |

## 四、开关设计盘点（现状）

### 4.1 编译期

| 开关 | 默认 | 构建 | 作用 |
|------|------|------|------|
| `TOY_BOOT_DEBUG` | 0 | ToyBoot `./build.sh DEBUG=1` | 仅 `BootDbg` |
| `TOY_DEBUG`（**现状名**） | 0 | ToyKernel `DEBUG=1` | `DebugWrite`/`DebugHex*` 空或开 |
| `TOY_SERIAL` | 1（build.sh） | `SERIAL=0` / `NO_COM1=1` | 总：不 Probe/Initialize UART；TX 全空 |
| `TOY_SERIAL_BOOT` … `_MISC` | 各 1（若总开） | `SERIAL_USB=0` 等 | 分模块 UART quiet |
| `TOY_SCREEN_LOG` | 1 | `SCREEN_LOG=0` | 总：boot GOP 不上字 |
| `TOY_SCREEN_LOG_*` | BOOT/USB/FS/GUI=1；其余 0 | `SCREEN_LOG_SMP=1` 等 | 分模块屏上 quiet |
| 头文件默认 | `ToySerialConfig.h` 内 `TOY_SERIAL` 默认 0 | 以 Makefile/`build.sh` 注入为准 | 课堂路径靠脚本打开 |

**通道 ID**：`TOY_SLOG_BOOT=0` … `MISC=8`（与上表一一对应）。

#### 4.1.1 必改命名（本柱约束，对齐 [`开发命名规范.md`](开发命名规范.md)）

| 现状 | 目标 | 说明 | 建议落入 |
|------|------|------|----------|
| `TOY_DEBUG` | **`TOY_KERNEL_DEBUG`** | 与 `TOY_BOOT_DEBUG` 对称；构建仍可 `DEBUG=1` → 注入 `TOY_KERNEL_DEBUG` | **PR-K-log-uart** 或同柱最早碰 `Debug.h`/`build.sh` 的刀 |
| `SerialInit` | **`SerialInitialize`** | 驱动层：名词+`Initialize`（见 [`开发命名规范.md`](开发命名规范.md) §2.1）；Hal 门面已是 `HalSerialInitialize` | **PR-K-log-uart** |
| 新建 Boot COM1 API | `BootSerialInitialize` / `BootSerialWrite` 等 | **层前缀在前** + **名词+动词**；禁止 `WriteBootSerial` / `*Init`；串口逻辑若膨胀 → `Boot.c` + `BootSerial.c`（§6.3，>300 行拆） | **PR-BOOT-log-uart** |

词序与拆分总则以 [`开发命名规范.md`](开发命名规范.md) §1.1 / §2.1 / §6.3 为准（**新代码强制，旧代码不翻库**）。

`Debug.h` 头注释、宏、Makefile `-DTOY_DEBUG=` 一并改名；直接全量替换，不推荐长期兼容别名。

### 4.2 运行时（屏幕侧）+ 编译期矩阵

| API | 作用 |
|-----|------|
| `HalSerialGopEnable` | video 就绪：允许 boot ring→GOP |
| `HalSerialGopMirror(0/1)` | 关/开 boot GOP 镜像（进桌面前关） |
| `HalSerialGopMute` | 临时禁屏（xHCI enum / PHOTO 等） |
| `HalSerialGopPhotoHold` | 真机读秒：白字日志当前行刷新（保留 `ToyOS boot` 横幅） |

编译期：`ChannelGopOn` ← `TOY_SCREEN_LOG` + `TOY_SCREEN_LOG_*`（与 UART 矩阵正交）。运行时 Mute/Mirror 仍是真机安全阀。

### 4.3 开关正交关系（简图）

```
TOY_BOOT_DEBUG ──────── BootDbg → 串口
TOY_KERNEL_DEBUG ────── DebugWrite → HalDebug → MISC UART
TOY_SERIAL ──┬── 0：无 UART
             └── 1 + TOY_SERIAL_<MOD> → ChannelUartOn → SerialWrite
TOY_SCREEN_LOG ──┬── 0：boot GOP 不上字
                 └── 1 + TOY_SCREEN_LOG_<MOD>
                        → ChannelGopOn →（Mirror && !Mute && VideoUp）GOP 上滚
ConsoleWrite ──── UART(MISC) + Shell FB（独立路径；本柱不纳入 SCREEN_LOG）
```

## 六、目标架构（柱完成后）

```
ToyBoot:
  COM1 Init → 横幅 ToyBoot / COM1 Serial OK
  块关节点 → 仅串口
  SetMode/确认分辨率 → 清屏（黑）
  JumpToKernel

ToyKernel:
  最早 COM1 SerialInitialize（幂等）→ 横幅 ToyKernel / COM1 Serial OK
  video 前：仅串口
  video 后：同文 → UART + GOP 上滚（受总/模块开关；调试宏 = TOY_KERNEL_DEBUG）
  禁止 bring-up 全屏 Clear（接 Boot 黑底）
  行列 = f(分辨率, FontAdvance*)
```

### 6.1 开关模型（PR-K-log-switch ✅）

| 维度 | 串口 | 屏幕（boot GOP） |
|------|------|------------------|
| 总开关 | `TOY_SERIAL` | `TOY_SCREEN_LOG` |
| 模块 | `TOY_SERIAL_*` | `TOY_SCREEN_LOG_*` → `ChannelGopOn` |
| 运行时 | — | Mute / Mirror（真机安全阀） |
| 课堂默认屏 | — | BOOT/USB/FS/GUI=1；SMP/MEM/NET/DRV/MISC=0 |

Shell `ConsoleWrite`：**本柱不纳入** SCREEN_LOG（路线图「本柱不做」）。
