# ToyOS 自动化功能测试

> **状态**：第 1 步本地已实现（`ToyImage/Scripts/test-shell.sh`），未 TG。expect 已装。  
> **目标**：用 `ToyImage/Scripts/test-*.sh` 自动喂 Shell 命令并检查串口输出。  
> **已有**：GitHub CI 编三架构；`smoke-boot.sh` 等到 `ToyOS ready`；`smoke-virt.sh` 看 virt 启动。  
> **不做**：不改内核，不改构建脚本，不引入 pytest / gtest，不用 Python。  
> **实测发现**：`halt` 调 `HalCpuPark()`——CPU 停机但 QEMU 进程**不退出**；脚本超时后 kill QEMU 仍算 PASS（规格第 4-5 步）。脚本须用 **LF 行尾**，CRLF 会让 `#!/usr/bin/expect -f` shebang 把 `-f` 解析成 `-f\r` 而失败。

## 二、现有启动怎么接串口

`smoke-boot.sh` 清掉已有 QEMU，再跑：

```bash
run-split.sh --kill-qemu --headless
```

标准输出进日志，每秒看一次 `ToyOS ready` 或 `ToyOS 就绪`。看到就退出 0。它不往里送命令。

`--headless` 只加 `-display none`。串口仍是 `-serial stdio`。VGA 还在，所以进的是桌面里的 `ShellTask`，不是纯串口壳。`ShellTask` 会读 COM1：

1. 第一个回车调用 `GuiOpenShell()`，这一下不当成命令。
2. 串口出现 `toyos>`。
3. 之后的可打印字符进入命令行，`\r` 执行。

本机目前没有 `expect`。第 1 步开跑前要先 `sudo apt install expect`。

> **更新（2026-09-24）**：expect 已装（`/usr/bin/expect` 5.45.4）。`test-shell.sh` 已用 LF 行尾落地，`./test-shell.sh` 直接可跑，五条命令全过，`exit 0`。

## 三、第 1 步：`test-shell.sh`

`expect` 拉起 `run-split.sh --kill-qemu --headless`。断言只看这条命令之后、下一次 `toyos>` 之前的新输出。启动日志里已有 `TOYOS` 和 `[Mod] Scheduler`，不能对整段日志检索。

### 超时

| 等待 | 超时 | 失败处理 |
| ---- | ---- | -------- |
| 启动到 `ToyOS ready` | 90s | 打印日志尾部，exit 1 |
| `\r` 后到 `toyos>` | 10s | 打印日志尾部，exit 1 |
| 命令后到下一个 `toyos>` | 15s | 打印日志尾部，exit 1 |
| `halt` 后 QEMU 退出 | 10s | 强制 kill，exit 1 |

### 日志

```tcl
set LOG "/tmp/toyos-test-shell.log"
log_file $LOG
```

失败时打印日志尾部：

```tcl
proc fail_dump { } {
    send_user "=== FAIL, log tail ===\n"
    catch { exec tail -80 $LOG }
    exit 1
}
```

### 清理

脚本结束时杀掉 QEMU，并注册退出钩子：

```tcl
proc cleanup { } {
    catch { exec pkill -f "qemu-system-x86_64" }
}
```

开跑同样会先杀掉本机上已有的 `qemu-system-x86_64`。

### 断言

| 命令 | 断言 |
| ---- | ---- |
| `help` | `commands:` |
| `ls` | `TOYOS.DB` |
| `lsdev` | `Bound Drivers` |
| `show memory` | `physical memory` |
| `list tasks` | `pid=` |

### 结束

1. 五条命令都通过。
2. 发送 `halt`。
3. 等 QEMU 退出，最多 10 秒。
4. 未退出则 kill（实测：`halt` 调 `HalCpuPark()`，QEMU 进程不退出，必走此步）。
5. `exit 0`（kill 后仍算 PASS）。

### 失败

1. 打印日志尾部。
2. kill QEMU。
3. `exit 1`。
