## 一、必须先固化（开课前冻结，之后只增不改）

### 1. syscall ABI

#### 权威与一致

- 以 [`Include/SyscallABI.h`](../../Include/SyscallABI.h) 为**唯一权威号表**。
- [`User/include/toyos/syscall.h`](../../User/include/toyos/syscall.h) **必须与之完全一致**（同号、同符号；禁止学生侧另起一套号）。

#### 号段规则（写死）

| 号段 | 功能族 |
| ---- | ------ |
| 0–99 | 进程 |
| 100–199 | 信号与调度 |
| 200–299 | 内存 |
| 300–399 | 文件基础 |
| 400–499 | 文件高级 |
| 500–599 | 目录 |
| 600–699 | 管道 / IPC |
| 700–799 | 时间 |
| 800–899 | 网络 |
| 1000–1099 | GUI 基础 |
| 1100–1199 | GUI 高级 |

**承诺**：本课程期间 **「只增不改」**——已公布号码语义不变；新能力只占用段内空号（紧接已用号），不挪号、不复用旧号。

#### 参数寄存器约定（x86_64 `syscall`）

| 角色 | 寄存器 | 说明 |
| ---- | ------ | ---- |
| 号 | `rax` | `SYS_*` |
| 第 1 参 | `rdi` | |
| 第 2 参 | `rsi` | |
| 第 3 参 | `rdx` | 部分调用另作**出参**（见 wait） |
| 第 4 参 | `r10` | （若需要；勿与 Linux `rcx` 混淆：`syscall` 指令占用 `rcx`） |
| 第 5 参 | `r8` | |
| 第 6 参 | `r9` | |

Arm64 / RiscV：由 HAL 把架构约定寄存器填进同一套逻辑参数槽；**号与语义与 x86 一致**。学生课默认以 x86_64 QEMU 为准。

#### 返回值语义（逐类）

| 类型 | `rax`（主返回） | 其它 | 说明 |
| ---- | --------------- | ---- | ---- |
| 成功（多数） | `≥ 0` | — | 如 fd、字节数、pid、break |
| 失败（带 errno 风格） | **负** errno | — | 如 `-ENOENT`；CRT 可转 `errno` + `-1` |
| 失败（布尔/句柄风格） | `-1` | — | 部分 CRT 包装后对用户表现为 `-1` |
| 成功无数据 | `0` | — | 如部分 close / munmap |

具体每个 `SYS_*` 的「负 errno vs -1」以实现与 [`开发/API速查.md`](../开发/API速查.md) 为准；**开课前须在讲义里用一张表钉死**（见 §二·8）。

#### 未知 syscall

- 未知号必须返回 **`-ENOSYS`**。
- **不崩、不刷屏**；现有 `syscall: unknown 0x..` 类日志要**收敛**（可一次摘要 / 限次，勿每 tick 打）。

#### `wait` 语义（再钉死 · 非 POSIX `waitpid`）

`SYS_WAIT`（52）：

| | |
| -- | -- |
| 入参 | `rdi` = options；可选 **`WNOHANG`（1）**；无 pid 参数 |
| 已有僵尸 | 立即返回：子 Id → **`rax`**；退出码 → **`rdx`** |
| 无子进程 | **`rax = -1`** |
| `WNOHANG` 且子仍存活 | **`rax = 0`** |

CRT：`pid_t wait(int *status)`；`*status` 编码为 `(exit & 0xff) << 8`；`WEXITSTATUS(s)` = `((s) >> 8) & 0xff`。

**与 POSIX `waitpid` 不同**——必须写进讲义（无 pid、rdx 旁路退出码、WNOHANG 返回 0）。

#### GUI 号

- GUI 已在 **1000+**（如 `SYS_CREATE_WINDOW` 1000、`SYS_DAMAGE` 1001、`SYS_POLL_INPUT` 1002、`SYS_UI_BUTTON` 1003、`SYS_DAMAGE_RECT` 1100）。
- **旧号 18 / 19 / 20 / 21 不得再出现在任何学生可见文档**（讲义、速查卡、作业、幻灯）。

#### 验收

```bash
# 号段与符号一致（实现刀落地后）
diff -u <(grep -E '^#define SYS_' Include/SyscallABI.h | sort) \
        <(grep -E '^#define SYS_' User/include/toyos/syscall.h | sort)
# 或确认 syscall.h 直接包含 / 同步自 SyscallABI.h
```

- 未知号用户态测试：调用未定义号 → 返回 `-ENOSYS`，机不挂。

### 2. CRT / libtoyos 接口

#### 版本

- 版本宏 `TOYOS_CRT_VERSION_*` 当前目标 **1.4.0**。
- 开课期间 **只升 MINOR**（不升破坏性 MAJOR）。

#### 《CRT 冻结清单》（承诺可用）

| 头 | 承诺符号 |
| -- | -------- |
| `<stdio.h>` | `printf` / `sprintf` / `snprintf` / `fopen` / `fread` / `fwrite` / `fseek`（及课上已用的 `fclose`/`ftell` 若已在库中则一并承诺） |
| `<stdlib.h>` | `malloc` / `free` / `realloc` / `calloc` / `atoi` / `qsort` / `exit` |
| `<string.h>` | 常用：`strlen` / `strcmp` / `strncmp` / `strcpy` / `strncpy` / `memcpy` / `memset` / `memcmp` / `strchr` / `strstr` 等已存在集 |
| `<unistd.h>` | `read` / `write` / `open`（经 `<fcntl.h>`）/ `close` / `lseek` / `fork` / `wait` / `pipe` / `dup` / `execve` / `brk` / `kill` / `mmap` / `munmap` / `sleep`（及已有 `msleep`/`clock_ms` 若课用） |
| `<dirent.h>` | `OpenDirectory` / `ReadDirectory` / `FileStat`（及课用 `CloseDirectory` / POSIX 宏别名若已提供） |
| `<sys/stat.h>` | `stat`（及已有 `fstat` 若课用） |
| `<signal.h>` | `signal` / `kill` |

#### 不承诺

- 完整 POSIX  
- 线程 / TLS  
- `.so` 完整重定位（仅教学级 JUMP_SLOT 演示）  
- `getcwd` / `chdir`：**已有但标注「实验」**，不进第一周必考  
- 完整文件映射语义（超出课上演示的 `mmap` 子集）

#### 讲义红字

1. **`fopen("w")` 不截断**（内核忽略 `O_TRUNC`）——学生不得假设 POSIX 截断行为。  
2. **`wait(int *status)`** 在 `User/include` 与 `User/crt` **签名必须一致**；`WEXITSTATUS` 编码写进讲义。

#### 验收

- `grep` 头文件声明与 CRT 实现签名一致。  
- 清单内每个函数在 `libtoyos.a` 有符号（`nm libtoyos.a | grep …`）。

## 二、教学基础设施（开课前强烈建议补）

### 5. 学生第一周环境检查清单

逐步（每步写**预期输出**与**常见错误**）：

1. 安装 **QEMU + OVMF**  
   - 常见错：OVMF 路径不对（`OVMF_CODE`/`OVMF_VARS`）。  
2. **clone 三仓**（ToyKernel / ToyBoot / ToyImage）  
3. `./build.sh`（ToyKernel，至少 x86_64）  
   - 常见错：交叉编译器 / `Tools/Extract` 未解压。  
4. `./Scripts/run-split.sh`（ToyImage）  
   - 常见错：残留 QEMU 占盘；先 `--kill-qemu`。  
5. 串口 / 屏见 **ToyOS ready / 就绪**  
6. Shell：`exec HELLO.ELF` → 见 Hello  
7. `make -C User/Pkg`（或 SDK 目录）出 `MYAPP.ELF`  
8. 拷到 rootfs → `exec MYAPP.ELF`

（实现刀：把上表扩成带「预期日志摘录」的 checklist 页。）

### 6. 单页 A4 速查卡

- 五类：**进程 / 文件 / 内存 / GUI / 网络**。  
- 每函数一行：签名 + 返回值 + 最小例子。  
- 复用 [`开发/API速查.md`](../开发/API速查.md)，**只保留本课程承诺面**（与 §一 冻结清单对齐；砍掉不承诺项）。

### 7. 统一自动化测试入口

新增 `./Scripts/test-all.sh`（或 `make check`），串跑：

```text
smoke-boot / smoke-virt / test-shell / test-user / test-fs

```

- **不依赖真机**；一条命令全绿。

### 8. 错误码约定表

用一张表写死（进讲义），至少覆盖：

| 调用 | 成功 | 失败 | errno / 说明 |
| ---- | ---- | ---- | ------------ |
| `open` | `fd ≥ 0` | `-1` 或负值 | 路径不存在等 |
| `read` / `write` | 字节数 | `-1` / 负 | EOF=`0`（read）等 |
| `fork` | 子：0；父：子 Id | `-1` | |
