## 一、目标与硬约束

### 目标

1. 左栏在「全部 / 已绑定 / 未绑定」旁（或之上）增加 **Summary**。  
2. 选中后展示类似「关于本机」的只读页：OS 版本、CPU、内存、硬盘等。  
3. 与现有设备列表/详情 **互斥切换**（选 Summary 不假装选中某 PCI 行）。

### 硬约束

| # | 约束 |
| - | ---- |
| 1 | **只读**观察面；禁止 Bind/Unbind/改驱动/写配置空间 |
| 2 | UI **不** include HAL 私有头；经 `Hal.h` / Core 公共 API |
| 3 | 新 `.c` ≤300；**勿**继续胀 `DevicesUiPaint.c` 过 300 |
| 4 | **不**改 Device 表语义、**不**改驱动 Probe |
| 5 | **不**占文首 ★，除非明文改 ★ |

### 明确不做

- ❌ 完整硬件清单导出 / 与 `lsdev -v` 逐字段对齐（可另链「打开设备列表」）  
- ❌ 设置页改主机名、用户账户（属 Settings）  
- ❌ 磁盘分区管理、格式化、安装器逻辑  
- ❌ 实时性能曲线（CPU%/MEM 刷新可后置；首版静态开窗刷新即可）  
- ❌ 设备树图形拓扑（阶段 3 另刀）

## 二、现状锚点

### 2.1 DevicesUi 布局

三栏（宽窗）：

| 区 | 现状 |
| -- | ---- |
| 左 | `DEVUI_SIDE_W=96`；标题 + **3** 筛选：All / Bound / Free（`DEVUI_FILT_*`） |
| 中 | Device 列表（PCI 位 + `Name`） |
| 右 | 选中设备详情（VID:DID、驱动、BAR 基址） |

窄窗无左栏时仍只有列表/详情；Summary 首版可要求「宽窗才显示左栏」（与现逻辑一致），或窄窗用顶栏 Tab——**推荐跟随现宽窗左栏**。

### 2.2 可复用数据源（已有）

| 信息 | 建议 API | 备注 |
| ---- | -------- | ---- |
| CPU 型号串 | `HalCpuInfo()` | x86 已有；Arm/RiscV 有占位串 |
| 逻辑 CPU 数 | `HalCpuCount()` | |
| 是否虚拟机 | `HalCpuIsHypervisor()` | 可选一行「虚拟化：是/否」 |
| 内存总量/空闲 | `PhysicalMemoryTotalPages` / `FreePageCount` | 页×`PAGE_SHIFT` → MiB |
| 帧缓冲 | `BootInfoGet()` → 宽高/像素格式 | 「显示器」简述 |
| 块设备 | `BlockDriveReady(Drive)` 等 | 容量 API **弱**；首版可只列 Drive 就绪 + 后端是否 Ready |
| 设备统计 | `DeviceCount()` + 可数 Bound | 「PCI 设备：N」 |
| 卷 | `FileSystem` 卷枚举（若 UI 层已能安全调用） | 可选「存储：TOYOS / …」 |

### 2.3 版本缺口

- 用户态有 `TOYOS_CRT_VERSION_STRING`；**内核 DevicesUi 不宜依赖 User 头**。  
- 需在 Common/Include 增加例如 `TOY_OS_VERSION_STRING`（或读已有构建宏）——**本柱第 1 刀一并定名**。

### 2.4 命名易混

阶段 1 `lsdev` 示意里的 `=== Summary ===`（Total/Bound **设备计数**）**不是**本柱 GUI「系统摘要」。  
文档与 Locale 键建议：GUI 用 `MSG_DEV_ABOUT` / `MSG_DEV_SUMMARY`；Shell 计数段保持 `Summary` 或改为 `Totals`（阶段 1 实现时再定，避免混谈）。

## 三、设计

### 3.1 交互

```text
左栏：
  [摘要]     ← 新；默认开窗可选停在「全部」或「摘要」（建议默认仍「全部」）
  [全部]
  [已绑定]
  [未绑定]

选「摘要」：
  中+右合并为 About 页（或中栏全文、右栏隐藏）
  gDevUiSel 对 Device 无意义；刷新只重读系统字段

选 All/Bound/Free：
  恢复现有列表+详情
```

点击：现有侧栏 hit-test 扩展第 0 项为 Summary（或末项；**推荐置顶**，更像「关于」）。

### 3.2 摘要字段（首版必做 / 可选）

| 行 | 必做 | 内容示例 |
| -- | ---- | -------- |
| 操作系统 | ✅ | `ToyOS 0.x.y`（常量）+ 可选 Arch（`x86_64`） |
| 处理器 | ✅ | `HalCpuInfo()` + `× N`（`HalCpuCount`） |
| 内存 | ✅ | `Total MiB` / `Available MiB` |
| 硬盘 | ✅ | `Drive0 ready` … 或「块设备：已挂后端 / N 盘就绪」；有卷则列卷名 |
| 显示器 | 推荐 | `WxH` @ bpp（BootInfo） |
| 虚拟化 | 可选 | Hypervisor 是/否 |
| 设备表 | 可选 | `PCI devices: N`（链到「全部」心理预期，不强制跳转） |

缺数据时显示 `-` 或 Locale「不可用」，**不**崩溃。

### 3.3 观感示意

```text
┌─ 设备 ─────────────────────────────┐
│ 摘要 │  About this computer        │
│ 全部 │                             │
│ 已绑定│  Operating system  ToyOS … │
│ 未绑定│  Processor         QEMU… ×4│
│      │  Memory            2048 MiB │
│      │  Disks             2 ready  │
│      │  Display           1024×768 │
└──────┴─────────────────────────────┘
```

中英随 `LocaleGet()`；标签走 Locale，数值走格式化缓冲（十进制 MiB，**勿**只打 hex）。

### 3.4 代码落点（建议）

```text
Include/DevicesUiPrivate.h     # DEVUI_FILT_SUMMARY 或独立 gDevUiMode
Common/Services/DevicesUi/
  DevicesUiSummary.c           # 采集 + 绘制 About 页（≤300）
  DevicesUi.c / Model / Paint  # 侧栏多项、模式切换、委托 Summary
Include/ToyOsVersion.h         # 或并入 Kernel.h：TOY_OS_VERSION_STRING
```

`DevicesUiPaint`：若 `Mode==Summary` → `DevicesUiPaintSummary(...)` 后 return；否则现逻辑。

### 3.5 与其它设备管理器文档边界

| 文档 | 本柱关系 |
| ---- | -------- |
| 阶段 1 增强 | FriendlyName 等**不依赖**；Summary **不**展示每设备 BAR |
| 阶段 2 Match | 无关 |
| 阶段 3 树 | DevicesUi 树状仍「另刀」；本柱不做树 |
| 阶段 4 资源 | 无关；Summary 不显示 MMIO 冲突 |
| 已完 DEV-6 | 本柱为其 **GUI 续篇** |
