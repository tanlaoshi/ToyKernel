## 一、门槛

| 项 | 约定 |
| --- | --- |
| 单文件 | 每个 `.c` **≤300 行**。超过不收刀 |
| 形态 | 每个功能模块 = **1 个核心文件 + 数个辅助文件** |
| 目录 | 核心与辅助 **放进同名子目录**。核心文件与目录同名 |
| 辅助文件名 | 模块名 + 能力名，PascalCase（`GuiDragComposite.c`） |
| 纪律 | 只搬家，不改行为、不改结构体布局、不改对外 API、不顺手改旧函数名 |
| 粒度 | 一个 PR 只动一个模块。不要一次把整张表做完 |
| 验证 | `./build.sh`；桌面 / 键鼠 / 控制台再 `smoke-boot`；ToyBoot 再手测一次开机到 `ToyOS ready` |

已经不超过 300 行、而且仍是单文件的，**不为建目录而搬家**。跨模块共享头留在 `Include/`（如 `GuiPriv.h`），不塞进某一个子目录。

先例：`HAL/X64/Drivers/XHCI/`、`User/Library/ToyUi/`。

`Makefile` 现在是 `wildcard Common/Services/*.c`，**不进子目录**。某个模块第一次开目录时，同一刀补上该目录的 wildcard。这只是把新文件编进来。

`GuiWm.c`（182 行）和 `GuiCompose.c`（249 行）已经达标，**不再重切**。路线图旧序「GuiWm → Compose → Console」的前两段核心已完成；本轮从仍超标的窗口旁支开始，再回到 Console。

全树仍约 **62** 个实现文件超过 300 行。`ToyBoot/Boot.c` 为 **1257** 行。

| 文件 | 放什么 | 现在 |

## 七、每刀验收

1. 本刀碰到的每个 `.c` ≤300 行。
2. `./build.sh` 成功；镜像里的内核已换。
3. 窗口 / 桌面 / 控制台：`smoke-boot` 到 `ToyOS ready`。拖窗刀再拖一次窗口。
4. 串口无新的 `EXCEPTION`。
5. 不夹带功能改动。旧符号名保持。
