# 应用商店规划（下载驱动 / 程序）

> 总规划 + **S0～S3 ✅**。排期见路线图 **1.3s**（续 **S4～S5**）；依赖组合见 **1.3m**。

---

## 1. 目标（用户原话对齐）

- 能浏览可安装项（程序 ELF、可选「驱动包」）  
- 能下载并落到系统卷（`TOYOS:`）  
- 驱动与应用分栏；失败可回滚/提示  

**非目标（明确不做或远后置）**：账号体系、付费、沙箱签名 PKI 全家桶、后台自动更新守护进程。

---

## 2. 依赖与现状

| 依赖 | 现状 |
|------|------|
| 网络 | virtio-net / e1000（**H4 ✅**）；用户态 socket 需 `LWIP=1` |
| 文件系统 | VFS + FAT ✅；写文件 ✅（FS3） |
| 包格式 | **S0 ✅** 约定；**S1 ✅** Shell 安装到 `Apps/` |
| 驱动热加载 | **无**——今日驱动是内核链接 + `ToyDriverRegister` |

因此：**第一期应用商店只装用户态 ELF（与主题/资源）**；「下载驱动」若指内核 `.ko` 式热插拔，须先有加载器——建议二期。

---

## 3. 分阶段

### 期 0 — 文档与目录约定（**PR-S0 ✅**）

Guest（`TOYOS:`）布局：

```text
Apps/                     # 已安装 ELF（可写；S0 空占位）
Store/                    # 本地/下载缓存（可写；S0 空占位）
Assets/Store/
  README.md               # 字段说明
  catalog.txt             # 离线目录样本
  packages/<id>/          # 可选 PKG.TXT + 载荷（S1）
```

仓库源：`ToyKernel/Apps/`、`Store/`、`Assets/Store/`；由 `prepare-rootfs` / `prepare-virt-rootfs` 同步进镜像。

### 期 1 — 「本地商店 / 优盘商店」（**PR-S1 ✅**）

- Shell：`store list` / `store install <id>` → 复制到 `Apps/`  
- 载荷：`Store/`、卷根、或 `Assets/Store/packages/<id>/`  
- 验收：无网 `store install hello` 后 `Apps/HELLO.ELF` 可 `exec`  

### 期 2 — 联网下载（**PR-S2 ✅**）

- 内核 `StoreNet.c`：内建 TCP 客户端 + **HTTP/1.0 GET**（无需 lwIP）  
- Shell：`store sync` / `store fetch <id>` / `store repo [ip:port]`  
- 仓库：宿主 `python3 -m http.server 8080`；Guest 默认 `10.0.2.2:8080`（`ToyDB store.repo=`）  
- 落盘：`Store/catalog.txt`、`Store/<file>`，再 `store install`（S1）  
- 校验：`sha256=-` 跳过；**8 位 hex** = 教学 **FNV-1a-32**（非真 SHA-256）  
- 演示树：`ToyImage/store-repo/`  

### 期 3 — 「驱动包」（**PR-S3 ✅**）

| 档 | 含义 | 难度 |
|----|------|------|
| A. 资源型驱动包 | 固件 blob、字库、配置，仍由**已链进内核**的驱动读取 `Assets/` | ✅ 已做（`sun8` / `demopack`） |
| B. 可加载 HAL 模块 | 单独 ELF/blob + 导出 `Register` | 高；另立项 |

**建议**：商店 UI 可叫「驱动」，期 3 只做 **A**（已交付）。

### 期 4 — 干净安装 / 卸载与可见性（**PR-S4 / S5**）

| PR | 交付 | 验收要点 |
|----|------|----------|
| **S4** | 安装清单与卸载 | ToyDB/清单记录已装项与依赖；`store list-installed` / `store remove`；卸后 `Apps/` 与元数据一致、无孤儿 |
| **S5** | 商店可见性 | Shell 或薄 Store 窗：已装 / 可装 / 依赖一行可见（教学级，非 Windows 卸载器） |

**不做**：Windows 级卸载器、账号/付费、后台自动更新。

依赖字段与「功能 = 多包组合」演示挂路线图 **1.3m**（**M1** 接 S4；**M2** 接 M1）。

## 4. 包格式（S0 定稿草案）

### 4.1 `catalog.txt` 行

```text
id|type|version|file|sha256|arch|title
hello|app|1|HELLO.ELF|-|x86_64|Hello
```

详见 [`Assets/Store/README.md`](../Assets/Store/README.md)。

**草案（S4 / M1）**：可增可选字段 `depends=`（逗号分隔包 id）；缺依赖时安装提示、不静默强装。

### 4.2 `PKG.TXT`（包目录内，可选）

```text
name=guidemo
type=app          # app | font | asset
version=1
file=GUIDEMO.ELF
sha256=-
arch=x86_64
title=GUI Demo
depends=          # 可选；S4/M1：逗号分隔包 id，如 font-cjk16,theme-demo
```

安装动作（**S1**）：校验 → 写入 `Apps/` 或 `Assets/` →（可选）DB `store.installed.<id>=1`。  
**S4** 起：写入/维护已装清单；**`store remove`** 按清单删载荷并清元数据。

## 5. 与 ToyDB

- `store.repo=10.0.2.2:8080` 仓库地址（**S2**，ip:port；非完整 URL）  
- `store.last_sync=`  
- 已安装列表：**S4** 起以清单/DB 为准（与 `Apps/` 对齐）；此前可扫描 `Apps/` 作缓存  
- 草案键：`store.installed.<id>=1`、`store.depends.<id>=a,b`（具体键名实现时定）

## 7. 安全（教学级）

- 默认只信课堂仓库；提示「可执行代码来自网络」  
- 不实现内核态任意下载执行；安装后仍走现有 `exec`
