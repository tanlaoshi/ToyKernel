# 应用商店规划（下载驱动 / 程序）

> 总规划 + **S0 ✅** 目录约定。排期见路线图 **1.3s**。实现逻辑从 **S1** 起。

---

## 1. 目标（用户原话对齐）

- 能浏览可安装项（程序 ELF、可选「驱动包」）  
- 能下载并落到系统卷（`TOYOS:`）  
- 驱动与应用分栏；失败可回滚/提示  

**非目标（明确不做或远后置）**：账号体系、付费、沙箱签名 PKI 全家桶、后台自动更新守护进程。

---

## 2. 依赖与现状

| 依赖 | 现状 |
|------|------|
| 网络 | virtio-net / e1000（**H4 ✅**）；用户态 socket 需 `LWIP=1` |
| 文件系统 | VFS + FAT ✅；写文件 ✅（FS3） |
| 包格式 | **S0 ✅** 约定；安装器 **S1** |
| 驱动热加载 | **无**——今日驱动是内核链接 + `ToyDriverRegister` |

因此：**第一期应用商店只装用户态 ELF（与主题/资源）**；「下载驱动」若指内核 `.ko` 式热插拔，须先有加载器——建议二期。

---

## 3. 分阶段

### 期 0 — 文档与目录约定（**PR-S0 ✅**）

Guest（`TOYOS:`）布局：

```text
Apps/                     # 已安装 ELF（可写；S0 空占位）
Store/                    # 本地/下载缓存（可写；S0 空占位）
Assets/Store/
  README.md               # 字段说明
  catalog.txt             # 离线目录样本
  packages/<id>/          # 可选 PKG.TXT + 载荷（S1）
```

仓库源：`ToyKernel/Apps/`、`Store/`、`Assets/Store/`；由 `prepare-rootfs` / `prepare-virt-rootfs` 同步进镜像。

### 期 1 — 「本地商店 / 优盘商店」（**PR-S1**，不强制外网）

- 从第二 FAT 卷或 `RES:`/优盘读 `catalog.txt` + 包文件  
- UI：Files 或简单 `Store` 窗列出 → 复制到 `Apps/`  
- 验收：无网也能「安装」`HELLO.ELF` 类演示  

### 期 2 — 联网下载（**PR-S2**）

- 最小 HTTP GET（可用户态客户端，或内核临时 helper）  
- 目录服务器：静态 HTTP 文件树（教学用 Python `http.server` 即可）  
- 校验：catalog / `PKG.TXT` 中 `sha256=`  

### 期 3 — 「驱动包」（**PR-S3**，仍保守）

| 档 | 含义 | 难度 |
|----|------|------|
| A. 资源型驱动包 | 固件 blob、字库、配置，仍由**已链进内核**的驱动读取 `Assets/` | 低，推荐先做（可与 **T3** 协同） |
| B. 可加载 HAL 模块 | 单独 ELF/blob + 导出 `Register` | 高；另立项 |

**建议**：商店 UI 可叫「驱动」，期 3 先只做 **A**。

---

## 4. 包格式（S0 定稿草案）

### 4.1 `catalog.txt` 行

```text
id|type|version|file|sha256|arch|title
hello|app|1|HELLO.ELF|-|x86_64|Hello
```

详见 [`Assets/Store/README.md`](../Assets/Store/README.md)。

### 4.2 `PKG.TXT`（包目录内，可选）

```text
name=guidemo
type=app          # app | font | asset
version=1
file=GUIDEMO.ELF
sha256=-
arch=x86_64
title=GUI Demo
```

安装动作（**S1**）：校验 → 写入 `Apps/` 或 `Assets/` →（可选）DB `store.installed.<id>=1`。

---

## 5. 与 ToyDB

- `store.repo=http://…` 仓库地址（S2）  
- `store.last_sync=`  
- 已安装列表：优先 **扫描 `Apps/`**，DB 仅作缓存  

---

## 6. 路线图挂点

柱 **1.3s**：S0 ✅ → S1 本地安装 → S2 联网 → S3 资源型驱动包。  
QEMU virtio-net 可先做 S2；真机网见 **H4**。

---

## 7. 安全（教学级）

- 默认只信课堂仓库；提示「可执行代码来自网络」  
- 不实现内核态任意下载执行；安装后仍走现有 `exec`
