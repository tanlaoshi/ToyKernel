# 应用商店规划（下载驱动 / 程序）

> **只规划，不实现。** ToyOS 教学向：可先做「目录 + 校验 + 安装到 FAT」，不做完整商业商店。

---

## 1. 目标（用户原话对齐）

- 能浏览可安装项（程序 ELF、可选「驱动包」）  
- 能下载并落到系统卷（`TOYOS:`）  
- 驱动与应用分栏；失败可回滚/提示  

**非目标（明确不做或远后置）**：账号体系、付费、沙箱签名 PKI 全家桶、后台自动更新守护进程。

---

## 2. 依赖与现状

| 依赖 | 现状 |
|------|------|
| 网络 | virtio-net / 规划真机 NIC（**H4**）；用户态 socket 需 `LWIP=1` |
| 文件系统 | VFS + FAT ✅；写文件 ✅（FS3） |
| 包格式 | 无；需自研极简 |
| 驱动热加载 | **无**——今日驱动是内核链接 + `ToyDriverRegister` |

因此：**第一期应用商店只装用户态 ELF（与主题/资源）**；「下载驱动」若指内核 `.ko` 式热插拔，须先有加载器——建议二期。

---

## 3. 分阶段

### 期 0 — 文档与目录约定（可与本文同期）

```text
TOYOS:/Store/           # 本地缓存
TOYOS:/Apps/            # 已安装 ELF 快捷方式或目录
Assets/Store/catalog.txt  # 可选：离线目录
```

### 期 1 — 「本地商店 / 优盘商店」（不强制外网）

- 从第二 FAT 卷或 `RES:`/优盘读 `catalog.txt` + 包文件  
- UI：Files 或简单 `Store` 窗列出 → 复制到 `Apps/`  
- 验收：无网也能「安装」`HELLO.ELF` 类演示  

### 期 2 — 联网下载

- 最小 HTTP GET（可用户态 `NETDEMO` 级客户端，或内核临时 helper）  
- 目录服务器：静态 HTTPS/HTTP 文件树（教学用 Python `http.server` 即可）  
- 校验：SHA-256 前 16 字节或整文件哈希写在 catalog  

### 期 3 — 「驱动包」（仍保守）

两种档次（选一写进课表）：

| 档 | 含义 | 难度 |
|----|------|------|
| A. 资源型驱动包 | 固件 blob、字库、配置，仍由**已链进内核**的驱动读取 `Assets/` | 低，推荐先做 |
| B. 可加载 HAL 模块 | 单独 ELF/blob + 导出 `Register` 符号，内核 loader `mmap`+调用 | 高；需模块 ABI、符号表 |

**建议**：商店 UI 可叫「驱动」，期 3 先只做 **A**；B 单独立项，勿与期 1/2 混仓。

---

## 4. 包格式草案（极简）

```text
name=guidemo
type=app          # app | font | asset-driver
version=1
file=GUIDEMO.ELF
sha256=…
arch=x86_64       # 或 arm64 / riscv64
```

安装动作：校验 → `FsWriteFile` 到 `Apps/` 或 `Assets/` →（可选）写 DB `store.installed.guidemo=1`。

---

## 5. 与 ToyDB

- `store.repo=http://…` 仓库地址  
- `store.last_sync=`  
- 已安装列表可 DB 或目录扫描（目录扫描更不易丢）

---

## 6. 路线图挂点

建议柱名 **1.3s**（Store）：S0 约定 → S1 本地安装 → S2 联网 → S3 资源型驱动包。  
依赖：**H4** 真机网仅当要在真机演示联网店时；QEMU virtio-net 可先做 S2。

---

## 7. 安全（教学级）

- 默认只信课堂仓库；提示「可执行代码来自网络」  
- 不实现内核态任意下载执行；安装后仍走现有 `exec`
