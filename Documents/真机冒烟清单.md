# 真机冒烟清单（PR-PC-smoke）

> **范围**：x86 **UEFI PC / 笔记本**（1.3c），不是 Arm/RiscV Board 包（1.3b）。  
> **无真机时**：先按「预期」勾选课堂 QEMU 等价项；有机器再填「实测」。  
> 机型约定与已知缺口：[`../HAL/X64/NOTES-UEFI-PC.md`](../HAL/X64/NOTES-UEFI-PC.md)  
> 课堂双盘 / QEMU：[`../../ToyImage/QUICK_START.md`](../../ToyImage/QUICK_START.md)

**图例**：`□` 未测 · `✅` 通过 · `❌` 失败 · `—` 本机无此硬件（记备注）

| 字段 | 填法 |
|------|------|
| 机型 | 例：ThinkPad T480 / 自拼台机 |
| 日期 | YYYY-MM-DD |
| 构建 | Kernel / Boot 提交或 `git describe` |
| 介质 | U 盘型号；ESP + TOYOS 分区布局 |

## 0. 上电前（介质）

| 0.4 | 固件：UEFI 启动；Secure Boot 关或已信任 EFI | 能进 Boot Menu 选 U 盘 | OVMF | □ |

## 1. 上电 → Boot → 进核

| # | 步骤 | 预期 | 课堂等价 | 实测 |
|---|------|------|----------|------|
| 1.1 | 固件加载 `BOOTX64.EFI` | 无立刻 Unsupported / 退回菜单死循环 | OVMF 加载 ESP | □ |
| 1.2 | ToyBoot 找 GOP + 含 `TOYOS.ID` 的卷 | 能读到 `Kernel.elf`；失败有 `Print` | 串口/屏见 Boot 日志 | □ |
| 1.3 | ToyBoot `jump` → `KernelMain` | 屏由 Boot 白字切到内核清屏色（深蓝灰） | `smoke-boot` / 有窗 `run-split` | □ |
| 1.4 | 模块跑完 | 桌面图标或壁纸色；或至少 GOP 有像素变化 | `boot: desktop ready` | □ |
| 1.5 | 就绪串 | 有 COM1：`ToyOS ready`；无 COM1：GOP 黄字控制台亦可（H3） | `smoke-boot.sh` 认 ready | □ |

停在 Boot 白字、从不见清屏 → 仍在 Boot / 进核缺页；见 NOTES §3。

| 3.3 | 无 USB 键时 PS/2 | `ps2-kbd` 绑定后可敲 | `boot: ps2-kbd keyboard` | □ / — |

| 3.5 | Caps Lock | 字母大小写切换；有灯尽量亮 | H2 | □ / — |

**未要求本清单**：USB hub、EHCI、真机 IOAPIC（→ **PR-H-ioapic**）。
